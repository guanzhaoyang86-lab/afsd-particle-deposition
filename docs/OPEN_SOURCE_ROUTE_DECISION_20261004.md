# 开源源码审计后的路线决定

2026-10-04；SOURCE_AUDIT / DIMENSIONAL_ASSESSMENT。不是 AFSD 过程模拟结果。

## 决定

1. **不迁移到 FE-SPH-GPU，也不直接移植其接触/热核。** 保留其公开源码用于几何、送料控制与方法比较。
2. **不再把继续堆纳秒真实动态步作为交付主线。** 原动态分支保留，作为局部参考和未解风险证据。
3. **下一实现优先级是同一 PySPH 设施内独立的热态准静态弹塑性原型。** 当前只进入“证明平衡初值及联合残差可解且成本可承担”的阶段；不是立即启动孔口全过程的准入证书。
4. **暂缓 OpenFOAM 后端迁移。** 其黏塑性路线仍是候选，但当前材料低率和边界缺口不会因换软件消失；先保留弹塑性固体描述，避免未经验证的黏度截断。
5. Siconos 保留为多面摩擦约束的方法参考；尚未证明其标准约化问题与本项目耦合切线兼容，不安装、不宣称可直接替代。

这是本项目当前约束下的研发投入选择，不是宣称准静态原型已经通过验证。若该原型的第一轮平衡/成本门槛失败，应停止该候选并报告原因，不能无限增加局部补丁。

## 本地模型本来已是热态，真正问题是初始平衡

真实运行的 `root/resolved_config.json` 给出 723.15 K（450°C）。此前调查中的“冷启动”用词已更正。当前动态状态包含预压接触和弹性瞬态；将温度升高或清零速度不会得到经过验证的平衡初态。

本轮只读诊断使用同一参数与现有 FKS 函数：在零塑性应变、450°C 下，率不大于 1/s 时屈服应力均约 1.51729 MPa。这是已声明 DEBUG rate_floor 的作用，不是对低率材料实验的拟合结果。

独立计算表明，若仅删除 rate_floor，当前参数的率因子在约 0.694313/s 变号，低于它将给负屈服。反过来，直接设置 `eta=Y/(3*rate)` 在趋零率时发散。故不能通过裁屈服、封顶黏度或偷偷增加黏性来把现有 FKS 包装成可用流体模型。准静态弹塑性原型可保留当前显式命名的低率假设与弹性支路，但必须处理屈服主动集、刚体模式和接触切换；其材料精度风险不消失。

## 下一实现的范围和停止条件

下一模型命名为 `HOT_START_QUASISTATIC_ELASTOPLASTIC_AFSD_APPROXIMATE`，独立输出和初始化历史；保持 PySPH 为唯一活动后端。它省略惯性，不能与原动态轨迹拼接，不能冒称完整启动过程。

优先完成一个贯通的平衡初始化/过程候选接口：有限工具几何及实际孔口切换、材料更新和压力/密度闭合、约束反力、滑动/粘着、隐式热反馈。初始化加载/温度/应力历史必须事前说明；禁止从现checkpoint清零速度或随意将初应力清零。有限距离势与旧多面罚簧是不同接触模型，必须显式命名并独立记账。

第一停点是**当前小几何上的独立初态及一次联合过程候选的可解性/成本**，不以再增加一套27点固定几何制造基准作为主要成果。若活跃棱边仍只能报错，或停滑仍需原惯性 kick 才能定义，则尚无完整平衡残差，不进入真实AFSD根。尚未达到这个停点，不启动118步的长串试跑。最小短段可以保留有限棒材库存及顶部执行器，暂缓补粒事务；不能把插入粒子计为孔口通过。

对首个候选应先冻结并核对：自由自由度残差、约束反力、初始应力/塑性史、接触几何有效域、法向势能与壁功、摩擦热原符号、质量与热平衡。具体数值验收要根据选定离散方程事前登记；本报告不发明未实现接口的通过阈值。若无法构造或求解合理独立初态，或成本预估已经不满足≤600s，则停止该候选并报告，不放宽阈值。

后续输运成功仍需持续正向孔口通过、新增塑性及孔下铺展，并做同终时时间细化、空间敏感性和慢加载惯性参考比较。上述指标未获得前，模型级别保持原型；组件通过数量不用于替代输运。
