# 已接受0–30 ms路径的惯性遗漏量级诊断

主结果为 `outputs/coupled_cost_20261004/inertia_omission_30ms_v2.json`，原始诊断数组为
同目录 `inertia_omission_30ms.npz`。这是只读运动学/力尺度分析，物理、材料、接触和
NNPS求值次数均为0，没有新增接受时间或修改任何门槛，也不是惯性有效性验证。

282个真实checkpoint的保存速度确实为每步位移除以实际步长，与位置差分最大误差
3.852e-15 m/s。它代表准静态步内平均运动学速度，不能当作动态求解的瞬时速度。
对280个内部节点，使用相邻均速差除以两步中点的实际时间间距；即
`a[n] = 2*(vbar[n+1]-vbar[n])/(dt[n+1]+dt[n])`。该公式正确处理不等步长，
已用不等采样的二次位置函数作算术检查。最后一个可用加速度节点为29.9375 ms，
不向缺少后续接受帧的30 ms终点补造加速度。

对应节点的内力和接触力取自已接受字段匹配、SHA绑定的实际完整候选日志，按原始
PID排序核对。比值分母为 `sqrt(||f_internal||² + ||f_contact||²)`，不是二者之和的
近平衡余项。全部非约束自由度的惯性代理力 `m*a` 比值中位数2.585e-7，最大值
4.0296e-4，位于0.125 ms启动附近；0.5 ms以后277个节点最大6.8661e-7。
这些数值只是该准静态路径相对于现有整体/棒材力尺度的量级。

**基板非约束自由度无法用现有节点合力建立可靠分母。** 该组没有直接工具接触力，
保存的内力合力已经接近求根容差；用它相除会得到没有意义的大比值。v2对280个
此类节点均记录比值不可用，不以容差替换分母，也不以整体小比值宣称基板或所有
局部惯性都可忽略。原始v1算术报告保留，其基板比值被v2明确取代。逐粒子摘要
仅覆盖力尺度同时大于当前最大值1%及相应自由度求根容差包络的粒子，其余明确
计为未解析；这些只是诊断可计算性筛选，不是物理接受门槛。

初态静止至首步平均速度的最大变化为0.00445277 m/s，质量加权速度变化L2量级
1.02446e-8 kg·m/s。现有数据没有解析实际启动斜坡，故启动加速度保持未知。
数值差分还可能包含平衡求解和步长切换误差；本报告没有惯性动力学对照、局部
应力对力的分解或空间收敛证据，也不覆盖30 ms之后的首次穿越与肩下响应。
