# Q3：独立单边压头参考与整体接触审查

2026-10-01。本文是运行前独立推导，不调用被测材料/接触函数生成期望值；
不构成已执行测试的 PASS。来源为 Q2 已冻结制造问题参数及以下连续体推导，
不是论文参数表、实验数据或新的 AA6061 标定。旧 Q2 的位移回程允许拉力；
本 Q3 参考改为只能向材料施加压缩力的平面，不能直接套用 Q2 的回程终态。

## 物理、坐标与符号

- 初始立方体 `0<=X,Y,Z<=L`，`L=0.01 m`，`A=L^2=1e-4 m^2`，
  `V=L^3=1e-6 m^3`，`rho=2700 kg/m^3`，总质量 `0.0027 kg`。
- 小应变准静态制造材料：`E=70e9 Pa`，`nu=0`，`G=35e9 Pa`，
  `K=E/3`；塑性分支为关联 J2、无硬化、`Y=90e6 Pa`。
  弹性参考必须明确关闭塑性或采用不会屈服的独立基准材料，不能将该结果称为 J2。
- 三个零坐标面仅各自法向 roller 支承，正 Y/Z 面自由；因此均匀参考是单轴
  **应力**，不是限制横向运动的单轴应变。负 X 支承不做功。
- 刚体压头平面 `x=L+d(t)`；材料应位于平面左侧。压头无摩擦，切向自由。
  对一个候选表面点，`g=d-u_x>=0`；压缩法向力大小 `lambda>=0`，
  压头对材料力为 `-lambda*e_x`，且 `lambda*g=0`。
- `d(t)=-0.0004*t m`，`0<=t<=0.1 s`；
  `d(t)=-40e-6+0.0004*(t-0.1) m`，`0.1<=t<=0.2 s`。
  只规定压头运动，不规定脱离后的材料运动。
- 参考忽略惯性、热、有限应变密度、摩擦、接触热和表面演化。
  压头速度仅定义准静态加载程序，不证明实际动态接触时间尺度。

## 独立弹性参考

接触期间 `epsilon_x=d/L`、`sigma_x=E*d/L`，其余应力为零。
压头对材料总力 `R_x=A*E*d/L`，为负值；压头反力反号。
整体轴向刚度 `k=EA/L=7e8 N/m`，柔度 `1/k=1.428571428571e-9 m/N`。
峰值 `d=-40 um` 时 `sigma_x=-280 MPa`、`R_x=-28000 N`，
储能/加载功 `E*epsilon_x^2*V/2=0.56 J`。
弹性回程接触持续至 `t=0.2 s`，在原位零反力；终位移/应力/塑性功皆为零，
完整循环净功为零。若需严格正间隙的弹性脱离测试，须另行声明压头退至正位移
的测试程序；不能假装当前止于原位的程序已经包含一段正间隙运动。

## 独立 J2 压缩—零反力释放参考

令峰值压缩应变幅值 `a=0.004`，屈服弹性应变 `eY=Y/E`。
加载时 `sigma_x=-min(E*(-epsilon_x),Y)`；首次屈服发生于
`epsilon_x=-eY`。无硬化单轴应力状态的等效塑性应变增量等于轴向塑性
应变增量绝对值。到峰值后，回程只需卸掉弹性压缩，**不发生反向拉伸屈服**。

不再增加。这里的“保持”是无载准静态平衡结果，不许可给自由粒子写死一条轨迹。
小应变塑性不可压缩给残余 `tr(epsilon)=0`，不等于已验证有限变形体积守恒。
均匀连续体不存在残余自平衡应力；离散非均匀块可有空间误差和自平衡残余应力，
须逐项报告而不是改参考或裁应力。n3 恰好符合均匀解不证明 n5 空间收敛。

## 时间层、拐点和硬接触脱离的功账

接受活动区间内压头和材料接触点法向位移相同，因此
`Delta Wwall=R_mid*Delta d=R_mid*Delta u_contact=Delta Wcontact_material`。
脱离后 `R=0`，压头可以继续运动而材料不被拖拽，压头不再做功。
法向力/位移功不是热量；不能将材料塑性功、返回算法损失或账差补成摩擦热。

仅加载阶段，在每阶段 8/16 个均匀节点上对独立分段应力作端点梯形积分，
由于未精确落在首次屈服拐点，分别得到：

| 每阶段增量数 | 梯形加载功 J | 若释放准确分段后的净功 J | 净功减连续塑性功 J |
| --- | ---: | ---: | ---: |
| 8 | `0.300000000000000` | `0.242142857142857` | `-0.002142857142857` |
| 16 | `0.301875000000000` | `0.244017857142857` | `-0.000267857142857` |

这些是**独立均匀连续体在给定采样节点上的积分参考**，不是直接规定每个离散
SPH 算例必须同值。加入首次屈服事件节点可去掉该纯积分拐点误差，但不需要为
追求全绿现在改材料更新器。实际使用的节点/事件必须保存。

硬接触释放不能随意用整个跨事件压头位移积分：8 增量回程的释放发生在
`t=0.125` 与 `0.1375 s` 之间。前端压头 `d=-30 um`、材料反力 `-2000 N`；
后端压头 `d=-25 um`，材料只回弹到 `-27.142857142857 um`，反力为零。
整段压头端点梯形给 `-0.005 J`；真实接触活动部分为
`(-2000/2)*(2.857142857143e-6)=-0.002857142857143 J`。
两者差 `-0.002142857142857 J` 是跨脱离段错误使用压头位移，不应冒充塑性或热。

允许的最小实现是定位零反力事件并保存释放节点，将当前候选区间切成活动段
和开口段；或者明确保存/积分等价的活动段路径。对非线性/多接触问题，不能仅用
端点反力线性插值得出保证正确的事件时间；应从同一接受状态进行有界试探定位，
重算材料和平衡。不能跳过事件、发现功差后再加一笔“修正热/修正功”。
从候选发现拉力应切换为开放接触并重新解整体平衡；不是把拉力裁为零但保留
压头拖拽位移。初始/释放时 `g=0,lambda=0` 的 active/open 标签可有退化选择，
只要原始互补量和平衡正确；状态分类不能被当作材料运动规定。

## 整体切线、约束与耦合：独立算法审查

去除支承 DOF 后，令 `N` 抽取候选表面的 +X 法向位移；采用
`Fint(u)-N^T*lambda=0`，`g=d-N*u>=0`。若
`delta Fint=-K*delta u`，固定活动集合的线性化为：

    [ K   N_A^T ] [ delta_u      ] = [ Fint-N_A^T*lambda ]
    [ N_A   0   ] [ delta_lambda ]   [ d_A-N_A*u         ]

同一整体方程也可通过活动接触 DOF 的位移消元，解剩余自由块 `K_qq`，再从
实际内力恢复接触反力。所有试探必须读取同一已接受的 S/ep 状态，迭代不累计塑性。
开放点要满足间隙，活动点要满足压缩反力；活动集合更新后必须重新平衡。
切向 DOF 不得与法向一起固定。基准只处理已声明平面和候选面，不能据此宣称
一般形变表面碰撞检测、工具方孔或多面摩擦已经实现。

若完整支承后切线 `K` 可逆，可定义整体接触柔度 `C=N*K^{-1}*N^T`；
一般为稠密耦合矩阵，边界约束先进入 K，不能替换成各点独立的 `1/m`。
准静态平衡没有粒子惯性，`P/m` 本身也没有正确的静态柔度量纲。

**但理想塑性平台不能机械先求完整 K 的逆。** 均匀单轴已塑性载入的轴向切线
为零，完整未压头约束的 K 可有真实机制；该机制可被活动压头位移约束消除，
此时接触控制问题和 `K_qq`/鞍点系统仍可有唯一增量解。
因此全 K 条件数过大并不能自动判定受控接触问题不适定；也绝不能用 pinv、
加刚度或给材料加硬化掩盖。应检查实际所解的受限块/系统，并保存其条件数。
卸载为弹性分支，其柔度与载入平台不同；屈服角点的中心差分是双侧平均，
不能将它称为唯一物理一致切线。原 Q2 的局部 FD 仍是近似 Newton 求解器。

建议独立审查量：原始最小间隙/最小反力、互补积、自由平衡、接触材料/压头功、
自由点位移与压头位移的区别、脱离后 ep/P 不增长、拒绝试探不污染、标签置换
不影响力学，以及同一几何的重复增量检查。不能仅凭 `lambda>=0` 判成功。
力矩应注明参考/当前位置；小应变参考力矩不能冒充大转动角动量守恒。
