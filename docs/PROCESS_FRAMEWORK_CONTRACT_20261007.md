# 论文与用户视频驱动的 AFSD 框架修订

本轮是新独立热态工程近似框架，不修改旧源、旧 FAIL 或旧接受态。
PySPH 后端、材料、接触、热方程、守恒阈值、自由材料运动求解均保留。

## 证据与适用范围

- P0：`papers/sph_simulation.pdf`，PDF 第4页提供300 rpm、走速2.12 mm/s、
  1.5 mm层高和三档轴向进给；第6页图4/5为可变形棒/基板、刚性工具/底座。
- P0 第7页 §4.1：旋转工具接触基板加热，材料软化后缓慢抬升并送料填隙，
  随后离开初始驻留区走刀。具体时长缺失；不能按剪辑视频时长设物理驻留时间。
- 用户视频：`<LOCAL_USER_PROFILE>/Videos/NVIDIA/Desktop/Desktop 2026.10.07 - 19.49.30.01.mp4`，
  79.10 s屏幕录制、2560×1600、60 fps。关键帧可见已有层上的路径铺层、
  墙体堆积和表面修复。视频含多工件/材料/设备镜头，没有连续冷启动测量或尺寸标尺。
  视频原文件不改，关键帧及摘要另存；画面外的温度、压力、摩擦系数不能反推为输入。

## 已实现的框架改动

1. `afsd_process_motion_20261007.py`：独立的旋转、送料、走刀指令与精确积分；
   所有接触/邻域/观察共用同一区间位姿。跨阶段必须拆步。
2. `configs/process_framework_20261007.json`：20 ms热态起转、20 ms热态送料过渡、
   20 ms走刀过渡、100 ms匀速单道。时长全部是可见的工程假设，而非论文测量值。
   当前固定肩高，不模拟冷态下压/抬升；分阶段允许今后明确增加这类独立物理模型。
3. 10 mm真实三维可变形基板，底层固定；棒料仍只有原材料标签顶层z受控，
   xy和其余材料自由，由旋转方孔接触传递转动。没有给自由粒子预设旋转/铺展轨迹。
4. 全行程肩半径+2h缓冲，以及有限棒料执行器保留量检查。超出时拒绝建立该工况。
   2h是保守工程域预算，并非空间收敛证明。没有偷偷追加粒子或实现虚假的连续进料。
5. `afsd_process_framework_20261007.py` 直接继承既有 `RampedHotTrial` 的残差、
   切线和z执行器实现；新独立初态、新机器程序及完整能量/穿孔历史，旧态不迁入。
6. 可见邻域事件模块诊断遮挡/再可见事件。发现切换必须保留失败并要求同一物理
   子区间重求解；诊断区间不能变成接受态，也不保证只有缩dt就会成功。
7. 观察分开统计旋转传递、孔壁扭矩、穿孔、肩下环区和工具离开后的几何留存候选。
   初始肩下材料不计入新送料；几何留存不证明冶金结合。

## 本轮验证与预算（运行前登记）

先运行运动、工厂状态、观察、事件组件测试和未改算子复用检查；再执行一次
真实残差/切线成本测量。数值步骤使用同一物理初态的粗/细时间分辨率对照。
每个子进程内部上限540 s、外部上限600 s；预计完整子阶段超过450 s时不启动。
CPU单线程，不安装包、不换后端、不缩放质量/时间/模量。所有输出用新目录。

成本阶段和短探针均是独立框架诊断，`accepted=false/restart_allowed=false`。
每一候选检查力平衡、材料/热收敛、质量、穿透、完整前缀能量、标量/批量接触
等价、整路径可见性与连续接触壳；粗细还须原有全局/局部及穿孔ID比较通过。
不通过时保存真实失败和最后诊断前缀，不晋升为旧正式过程的继续结果。

本轮不承诺0.16 s完整沉积；该长度是工况计划，不能当作已执行时间。沿用的
2.5 mm缩小棒、450°C预热、初始预结合、准静态/FKS/恒热参数局限仍存在。
旧正式结果仍为62.1875 ms；新框架结果不能拼接到旧动画或旧接受时序。
