# 真实事件括区和自身路径延迟共同收敛

2026-10-10 用户要求解决长跑支持边切换停止。v4 prism 的第一档完整粗细 pair 已通过：18 次真实物理解，原全局/局部检查和支持边恢复均 PASS，末态 71.85107421874992 ms。其半容差档随后失败：8 个真实同父探针得到 blocked 低端 249.39009304025963 微秒、visible 高端 249.4350930402596 微秒，宽 45 纳秒、最大位置差 2.004768 纳米；但是高端自身路径 router 的 start_fraction=.9997591115534306，意味着其支持边可见后延迟恢复上界为 60.086032082 纳秒，超过该档 50 纳秒。此前 locator 只以真实端点括区和位置差停止，driver 后置的独立延迟门槛拒绝了该结果。这是真实失败，不应放宽门槛或用括区宽度替代自身路径延迟。

新增 afsd_event_locator_delay_20261010，继承已验证的真实同父端点 secant/二分提议、单调性检查、位置证据及 10 次定位预算。callback 必须提供 activation_delay_s：blocked 端点为 None；visible 端点为有限非负 dt*(1-router.start_fraction)。start 使用保守的最早转换端，而不是中点或 end。locator 成功必须同时满足真实 blocked/visible 正宽括区、原时间容差、原 50 纳米位置差以及高端自身延迟不大于同一时间容差。如果括区和位置已合格而延迟不合格，则继续原括区内真实二分求解；无剩余探针预算仍显式失败。延迟只参与停止条件，不改变端点分类，不用 router 时间或插值物性冒充真实状态。

额外的只读诊断显示，延迟刚好小于容差且余量不足约 1ns 时，原 blocked 前缀证明仍可能耗尽 256 查询。因此新 callback 在真实 visible 解的延迟已达标时，提前执行相同的原 blocked 前缀证明并保存独立探针证据；activation_prefix_certified 必须是原生 bool，blocked 解恒为 False，visible 解只在原证明 CERTIFIED 时为 True。只有无可见样本、无退化、无数值域/异常错误的原 256 查询纯预算耗尽，才允许以 False 在剩余定位额度内继续真实二分；实际几何或其它错误仍立即停止。locator 成功也要求该布尔值为 True，它不参与端点 blocked/visible 分类。对更近真实解再次证明不延长任何一次几何证明的预算，不伪造物理状态。

新增 run_gpu_visibility_event_delay_20261010 替换 locator 导入与版本注册，在原 solve_probe 中提供自身延迟和上述原前缀证明证据。后置 high_delay 门槛及完整 blocked 前缀证明仍独立重新计算并保留。除这些明确变化外完整 driver AST 不变：原 GPU 力学、材料、热学、同父初猜、共同邻域、prism 全路径证明、实际后侧恢复、粗细比较、源绑定、实际求解成本日志不变。原单次定位 10 次、pair 总物理解 25 次、时间容差 min(100ns,dt/1024)*scale 及 50nm 位置限值不变。没有扩大物理容差或预算。
