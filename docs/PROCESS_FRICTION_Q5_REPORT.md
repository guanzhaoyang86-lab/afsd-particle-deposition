## 实现与明确的边界改变

新scripts/probe_process_friction.py复用Q3 ContactBlock/Q2 PlasticBlock。
单壁X+的9接触点，27材料点，54永久自由DOF。为了不让摩擦切向与永久roller
重合，本制造问题改成**仅X=0面三分量夹持**，不保留Q3的Y/Z零面roller；
不是偷偷改变旧问题，配置/运行前CONTRACT均已明确，旧Q3/Q4照原样保留。
几何边长.01m、rho2700kg/m3、E70GPa、nu0、h/dx1.3不变；制造屈服1e12Pa
确保弹性测试，不能用本结果声称AA6061在约280MPa仍弹性。μ=.1是制造假设。
原实际Jaumann更新仍被调用，未用线性弹簧替代三维材料。

实际次序：

    advance（拒绝跨越壁程序拐点）
      → 微小纯trial探测粘/滑模式，不提交
      → accepted反力必须位于该滑移边界，否则回到粘着查找首次事件
      → branch：整体受限Newton + 实际材料trial/tangent
        → 法向λ=Fint_x；滑移τ=-μ*mode*λ
        → 自由滑移行R_y=Fint_y-μ*mode*Fint_x
        → 全局耦合切线行K_y-μ*mode*K_x，不做独立P/m限幅
      → 必要时二分首个粘滑边界并接受子区间
      → commit重算材料/反力/模式/功及metadata，统一提交
      → accepted时序、事件、原始逐接触功账

mode=0为区间粘着，±1是材料相对壁的滑移方向，不是壁速符号。
法向保持受压；若真实脱离超出本轮能力则BLOCKED，不裁负法向力。
Z切向无摩擦，不能旋转这个定向模型后就声称完整工具接触。
有限模式探针不能越过尚未到达的粘滑边界：独立near-start回归验证accepted-force
保护。其余仍限短单调程序支路，不证明任意非单调多事件/新碰撞检测。
