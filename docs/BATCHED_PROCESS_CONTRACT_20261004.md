# 相同有限接触模型的批量计算与续算（运行前）

目标是获得预算内的真实输运，不以微步数或单测数为成果。本次从上轮精细5ms状态
继续同一个热态QS工程近似；不改惯性假设、材料、几何、摩擦、热学和任一接受门槛。
原始标量接触源保留。新NumPy批量适配仅合并独立粒子的端点/中点距离查询；最近点
选择、并列拒绝、真实实体扫掠、功恒等式和负耗散检查必须保留。同一CPU单线程，
无GPU/质量时间模量缩放。跨步Jacobian缓存暂不实施。

## 先验证等价及实际成本

旧冻结源、参数和checkpoint必须匹配；批量源码、驱动及合同独立hash记录。
先跑独立批量/标量几何与完整接触对照（含活动并列、实体、棱边、旋转、摩擦历史），
以及原88选定组件与8个secant fixture。旧完整1246回归FAIL保持，不改成全绿。

选择旧粗pilot 4.5→5ms同一父状态/同一初值，对比完整候选的力、材料、热及能量；
再用旧Broyden控制器求同一根。固定候选要求位置/密度/温度/应力/ep/力及所有有限
接触浮点字段rtol<=1e-10（单位相关绝对底限见驱动），离散分支字段相同。
同根仍用旧门槛：位置<=10nm，T<=1e-4K，S/ep相对<=1e-3。只做重放，不增加时间。
报告完整评估与切线/根/发布耗时；cProfile时间不能用作生产成本。

## 启动后增步验证

上述通过后，从精细5ms同一父状态分叉：1×1ms与2×0.5ms都到6ms。
原每步位移/穿透50um、自由力、密度、温域、热账、全部累计能量门槛不变。
时间筛选仍为位置<=5um、T<=.5K、S相对<=10%、ep相对<=20%；分母地板沿用。
罚壳取样检查与原连续实体扫掠保留。非孔壁新feature暂不越过，出现即记录并停止，
另对真实事件做有界验证，不能直接删除事件守卫。两个分叉不得拼成一条物理时间。

若该1ms失败，保留失败，下一步另登记较小时间步或事件诊断，不自动无限减半。
若通过，以较细6ms状态为后续起点。进一步过程窗口必须先用实测根成本、1.5余量
及30s输出预留检查<=450s，每次内部540s/外部600s硬停。达到6ms不等于穿孔。
后续目标时段/窗口及对照将在启动前另立补充合同，不能事后改变本次阈值。

每次提交前重新evaluate/验原门槛，完整继承材料/接触/累计能量/ID和被动标签。
checkpoint保存数学模型源、批量实现源及父文件hash；所有旧输出不覆盖。
