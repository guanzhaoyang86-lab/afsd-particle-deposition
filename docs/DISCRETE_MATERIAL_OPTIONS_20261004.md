```
global_raw = material_raw + tangent_algorithm + release
             - normal_endpoint_error + residual_work - pair_work_error.
```

旧 0.5 ms 拒绝候选：

| 原始量 | J |

| normal_endpoint_error | -5.1209454665803254e-5 |

最后第二行只是**固定旧状态的项量级估算**。离散梯度法向力必须真正进入

新根的功尺度也会改变，不能直接沿用表中旧门槛作为新候选结论。

这个差距足以支持先单独集成法向离散梯度，再看实际材料缺口，避免同时更换
接触、材料更新和热源三个环节。原 FKS 径向返回及 `q_new * dep` 塑性热仍保留；
材料 BE 项和切向算法项继续留在原始误差门槛内，不能先扣除再宣称合格。

旧六步的 `sum(global_raw + normal_endpoint_error)` 为
`2.897880740394590e-7 J`，小于按旧功尺度计算的单次区间门槛
`3.972556292094310e-7 J`。但这**不保证每个前缀**：第二步累计仍为
`1.710267547846782e-7 J`，超过 `1.451423313939310e-7 J`。
前两步没有接触，因此 DG 法向不会修复这一启动阶段的材料 BE 缺口。
新验证应从已声明的独立初态重新求较大联合步，不能继承旧序列并改账后接受。

## 2. 平均应力能闭合代数，但不能直接替换塑性热

设 `H=dt L`，`E=dev(sym(H))`，`Q=exp(skew(H)/2)`。将端点应力转到
同一中点共转坐标：

```
A0 = Q S0 Q^T
A1 = Q^T S1 Q
P  = Q^T (1.5 * dep * S1/q1) Q
A1 - A0 = 2G (E-P)
Sbar = (A0+A1)/2
e = S:S/(4G)
Sbar:E = e1-e0 + Sbar:P.
```

因此 `Sbar` 与当前塑性返回可以形式上组成储能恒等式。但是
`Sbar:P` 不等于原算法的 `q1*dep`，而且并非普遍非负。
温度保持不变也不足以保证它近似真实塑性功：接近对称的反向塑性步中，
旧应力与新应力的平均值近零，塑性历程上的功却不是零。

已执行三个独立材料点。共同输入：原 FKS（仍有 `rate_floor=1/s`）、
`G=26.3 GPa`、`dt=.01 s`、`ep0=0`，初应力为 723.15 K 低率屈服状态：

```
q0 = 1517290.6902550498 Pa
S0 = diag(2*q0/3, -q0/3, -q0/3)
H  = diag(-.0002, .0001, .0001)
rate = .02 /s
```

表中的更新温度是独立施加的材料点输入，不是从 AFSD 热求解中产生：

| 更新温度 / K | q1 / Pa | dep | 原 endpoint 塑性功 / Pa | Sbar:P / Pa |
| --- | ---: | ---: | ---: | ---: |
| 723.15 | 1517344.7088259908 | 1.615382078697e-4 | 245.1091449843 | 0.0043630316 |
| 773.15 | 478087.2368259431 | 1.747100389470e-4 | 83.5266397659 | -90.7796379112 |
| 800.00 | 256995.9435571097 | 1.775122099644e-4 | 45.6199178927 | -111.8588528464 |

三个平均应力恒等式误差绝对值至多 `2.85e-14 Pa`。
这恰好说明“代数闭合”可以与“热源明显不合理”同时出现。不得将负值裁零；
仅在负值时拒绝也不能解决第一行几乎零塑性热的问题。
若以后研究该方案，至少需要识别屈服进入、卸载、反向再屈服和温度变化，
在材料子步上积分真实应力—塑性增量功，并重新建立整体力功一致性。
真正的中点屈服/流动规则则是另一种时间算法，需另检端点屈服是否可容许，
不能称为保留原端点返回规则。

作为手算对照：纯弹性卸载取 `H=-S0/(2G)`，则 `S1=0, P=0`，
`Sbar:H=-S0:S0/(4G)=e1-e0`。平均应力能正确处理该弹性例，
并不能免除上表的塑性反例。

## 3. 有限旋转与变体积也不能只改应力平均

如采用中点空间梯度，对于精确刚体转动 `x1=R*x0`：

```
H = 2*(R-I)*(R+I)^(-1).
```

在不跨越 180 度的增量下它是反对称张量，对转角 theta 的平面旋转，
其旋转参数为 `2*tan(theta/2)`。把 `exp(skew(H))` 用作总旋转会得到
`2*tan(theta/2)` 而不是 theta。Cayley 映射可在这一刚体基准恢复 R；
这不自动证明一般伸长加旋转下的客观精度。当前端点空间梯度在刚体旋转时
还含 O(theta^2) 的对称项，因此只替换材料应力平均不构成有限旋转修复。

若引入真正中点体积功，令 `Vm=(V0+V1)/2`、`ebar=(e0+e1)/2`，则

```
delta(Ve) = Vm*delta(e) + ebar*delta(V).
```

与 `delta(V)/Vm=tr(H)=c` 相容的密度闭合是
`rho1=rho0*(1-c/2)/(1+c/2)`，须有 `|c|<2`；这不是当前 BE 密度闭合。
使用当前 `e=S:S/(4G)` 储能时，材料算法应力还需包含 `+ebar*I` 才能
承担偏应力储能的体积项。该项改变了原 hypoelastic 体积力学，应明确作为
新模型假设评估，不能把它仅记为无影响的能量账补项。

现有体积储能 `Uv(V)=K[Vref*log(Vref/V)+V-Vref]` 可用离散压力

```
p_DG = -delta(Uv)/delta(V)
     = K*[Vref*log(V1/V0)/(V1-V0)-1].
```

当 V1=V0 时极限是 `K*(Vref/V0-1)`；接近该点必须稳定计算
`log1p(z)/z`。配合上述密度关系有 `-Vm*p_DG*tr(H)=delta(Uv)`。
即便这部分严格闭合，前节塑性热与有限应变 hypoelastic 闭循环问题仍未解决。
