# 独立热态准静态联合探针：实际实现、试跑及否定结果

本轮已经实现并运行新路线。结论是：**同一 PySPH 内的准静态联合力根能以可观测成本
求解，但当前端点时间离散的能量误差仍阻止有效过程步长，未得到可信孔口通过或沉积。**
逐步数值接受不等于整段能量合格；最终短序列的额外区间审计也未通过。

分类 `HOT_START_QUASISTATIC_ELASTOPLASTIC_AFSD_APPROXIMATE`。原惯性接受时间仍为
1.3503936329109039 us；本报告的新时间从独立初态计，二者不得相加。
没有切换后端、安装新数值依赖、质量/时间/模量缩放、GPU优化或三工况生产。

## 1. 已实现的联合模型

新增 `quasistatic_contact.py`、`quasistatic_tangent.py`、`quasistatic_energy.py`、
`quasistatic_process.py`。复用固定 PySPH 粒子/三维NNPS和项目原FKS/J2、修正配对力、
隐式热图、checkpoint和VTK输出。不是获得了某开源仓库的完整AFSD求解器。

新增模型假设及事前门槛见 `HOT_QUASISTATIC_PROCESS_CONTRACT_20261004.md`：
342点、450°C独立无应力初态；方孔2.504 mm，每侧2 um间隙；底层基板三轴夹持，
棒顶只规定z送料；棒/基板预粘结邻域。忽略惯性和热膨胀，沿用公开的FKS低率地板。
有限开放方孔的8个表面罚势叠加；唇边重复贡献明确保留，活动多最近点仍拒绝。
摩擦由工具体坐标切向簧和库仑返回决定，不覆盖材料速度；热源只含真实滑移和塑性功。

端点平衡、密度闭合、材料温度反馈及隐式热图共同求解。候选不更新历史，完整验收
才提交。算法耗散、释放能和法向端点功误差单列，没有加入温度、裁掉负值或从原始
能量门槛里扣除。新增有限几何和连续扫掠检查用于独立模型；没有删旧守卫冒充续跑。

## 2. 测试和成本门槛

正式选定回归 **48 PASS**（39项新增、9项原Q1重跑），测试体0.677 s。
这不是整个当前项目全量回归，不是48个AFSD物理验证。原精度FAIL没有改判。
开发中缺少SciPy/pytest及一个浮点全等断言失败均保留说明；最终无新增依赖。

独立初态：接触力与接触势能均为0；809自由度受约束弹性块最小特征值
91349.23 N/m、最大1.1837793e8 N/m，无阈值内未约束零模。这只检验初态结构，
不认证大变形后永远可解。

一个完整0.5 ms候选0.340908 s，切线和线性解0.786429 s，峰值约132.9 MB。
按每次Newton最多8次残差回溯、24次更新及1.5倍余量，根预算156.493 s，
通过450 s启动门槛。每次运行都有540 s内部和600 s外部硬上限。

## 5. 额外整段审计未通过：不能反复使用绝对容差声称精度

六个接受步确实逐个满足原登记门槛 `1e-7 J + 5%*当步绝对功尺度`。
但绝对项占各步门槛45.44%–90.19%；除尝试3外，当步raw/scale为9.13%–33.33%。
尝试9已使用门槛的99.608%。因此不能简称“误差低于5%”。

另作区间审计，仅给整段一次1e-7 J绝对余量：

- 累计原始缺口：6.078705286866111e-7 J。
- 累计绝对功尺度：5.945112584188619e-6 J；比例10.2247101%。
- 区间门槛：3.97255629209431e-7 J，**FAIL**。

这是额外审计，明确不伪称原driver已经执行该区间门槛，也不抹掉原逐步接受记录。
快照仅保留作研发证据；该序列**不具备过程续跑合格认证**。
详细推导及独立复核见 `HOT_QUASISTATIC_ENERGY_REVIEW_20261004.md`。

## 6. 路线判断与下一工作

有限工具、接触、材料和热学已经首次在这条独立准静态路线中形成可求解联合原型。
初态没有暴露零刚度问题；力根不是本轮首要失败点。主要障碍已定位为接触建立和
端点功积分的能量误差，而不是再缺一个局部材料响应补丁。

按本次启动平均速度，将250 um/2.12 mm/s=0.1179245 s直接线性外推约需
81519 s（22.6 h）。这不是生产时长预测，启动与稳态可能不同；但现有证据没有
证明能在600 s内得到孔口输运。继续原样堆微小步不满足当前过程目标。

下一项研发应为**能量一致的接触/材料时间离散与区间累计能量约束**，独立基准
先覆盖接触进入/离开、停滑反转、有限旋转和同区间细分。不应只改日志功公式来
消掉误差，或把逐步算法损失转热。随后再做一次同孔口有界试验。当前不启动
长程、小步堆叠、GPU或三工况，不宣称开源库迁移已经解决问题。
