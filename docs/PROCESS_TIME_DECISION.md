## 下一单元建议：同设施的工艺时间方法可行性关卡

建议先取得对“独立隐式/准静态可行性基准”的明确方向，再实施基准，
不是直接改生产默认。只选一个候选，不同时发展多后端。
保留现有显式求解器作为短瞬态/冲量与热账参考。

候选方向：在同一PySPH ParticleArray/NNPS/ID/输出之上，
用受约束整体力平衡处理慢加载；真实工艺dt仍用于应变率依赖材料和热学。
这是显式命名的ENGINEERING_APPROXIMATE数值方法变体，非现有求解器开关。
不预先承诺比显式快；大步接触切换、材料返回和空间零能模都可能阻塞。

独立开源方法参考仅限概念：MOOSE将静力平衡、惯性和时间积分明确区分，
并提供隐式动力学说明：[官方Dynamics](https://mooseframework.inl.gov/docs/site/modules/solid_mechanics/Dynamics.html)
（2026-10-01访问）。此来源不证明本项目SPH准静态适用/稳定或加速比；不安装MOOSE，
不复制其结果。以下方案是本项目推导，尚待独立检验。

## 最小接口与先后范围（均NOT_IMPLEMENTED/NOT_RUN）

1. 先审查mechanics.py现有corrected梯度/伴随力的离散切线与约束后零空间；
   cond(M)>1e6仍失败，不用pinv掩盖。固定小三维域，同几何/真实模量/质量。
   scripts下独立driver/test，不切换solver.py、material.py默认。
2. 试探残差接口residual(trial_displacement, accepted_state, physical_dt)：
   非线性迭代不得累加ep/塑性功/热；每次从同一accepted state计算候选，
   收敛后一次commit，否则全部回滚。自由材料位移由平衡求出，不预置轨迹。
3. 基准先用明确的制造弹性材料和受载块，独立连续体力/位移/功参考；
   确认约束反力、虚功、刚体零模、受约束稳定性、回滚、ID/标签独立。
   E2原有自由面误差单独报告；离散迭代收敛不等于连续体精度PASS。
4. 再测试小型多面接触+执行器。慢过程接触耦合需要结构切线和约束后的柔度，
   不能原样搬当前粒子P/m冲量限幅。规定入口/执行器与自由DOF仍分开，反力功记账。
5. 只有前项可行才接现有FKS/塑性及热；物理dt进入应变率，
   迭代次数/伪时间不可当送料时间。不得残差转热、人工质量/模量或隐藏阻尼。
   惯性可忽略性需要加载尺度与低速/显式参考证据；不能直接忽略最初冲击。

执行前再冻结基准几何/边界、独立reference、容限和<=60s单元预算；
本文件不事后授予新算法任何PASS。首次开发只做受载块与试探状态回滚，
不同时实现全局接触/FKS/热/入口，不建第二项目。
