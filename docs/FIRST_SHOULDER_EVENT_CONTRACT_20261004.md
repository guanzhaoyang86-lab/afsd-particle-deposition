# 首肩接触事件有界验证（运行前）

从已通过6→20ms最细对照的eighth第112步（累计136步）继续同一个热态QS工程近似。
20ms父checkpoint SHA为356ef74b474f52cef07455b64fb025b984c0939516b882865e57f24023e33832。
全部材料、接触、热学、累计能量和被动身份历史继承；不改变惯性假设、输入或缩放。
旧脚本不修改，新驱动、合同、连续罚壳审计及其已通过组件receipt独立冻结。
局部逐点门槛、一跳非递归邻域、标量接触元数据及未提交半步状态隔离另做独立fixture，
其源码与exit0 receipt也进入运行前冻结；这些测试不执行AFSD物理求解。

## Approach

固定dt=0.125ms，最多16步，从20ms至22ms。按eighth较大实际完整单根耗时，
16×耗时×1.5+30s必须不超过450s；内部540s/外部600s硬停，每根前检查剩余预算。
每步完整真实残差、fresh接受、能量全部前缀和原实体扫掠仍须通过。
另调用连续罚壳审计，仅CERTIFIED_NO_HIDDEN_SHELL_CONTACT可接受；FOUND或UNRESOLVED
停止，不把三点抽样当作连续无事件证明。证书只覆盖声明插值的两端均不活动patch对，
不替代真实连续轨迹或活动接触时间精度验证。

首次抽样发现任何非孔壁feature时，保留完整数值候选、真实粒子ID/feature/分数、
直接父路径和hash、dt和全部诊断，状态EVENT_CANDIDATE_NOT_ACCEPTED，不发布该步。
此前完整合格前缀保留。16步未遇事件则明确记录有界接近完成，不自动继续延长。

## Macro及halves

仅当首次新feature为SHOULDER，才从approach保存的同一直接父态重解1×dt与2×dt/2。
本次允许该首次肩接触参与方程；其他新feature、几何并列、实体穿入、吸引法向、
负耗散、隐蔽罚壳活动、温度/密度/位移/穿透和全部原能量拒绝规则仍保持。
每个候选做原标量与批量完整地图同候选对照，沿用batch.candidate_equivalence的
全部数组/材料/能量阈值，并核对非数组接触模型与实体证书元数据。

macro只形成数值合格NOT_RESTARTABLE候选，不发布。两个half也先形成未提交候选；
只有half2终时对macro全局位置<=5um、温差<=.5K、应力相对<=10%、ep相对<=20%通过，
且事件粒子及其一跳邻域逐粒子同门槛通过，才依直接父链原子发布两个half checkpoint。
局部应力用单粒子Frobenius范数及1MPa分母底限；ep用1e-5分母底限，不能用全域聚合
掩盖小区域偏差。一跳邻域取事件粒子在macro、half1、half2真实NNPS边的并集，不做递归扩张。
事件粒子取approach、macro、half采样肩接触ID并集。全局分母地板沿用原post.compare。
局部或全局失败时两个half全部保留UNCOMMITTED，不输出accepted。通过检查后的发布中断
可能保留已验证的第一half前缀；不会发布一个未经整段局部时间筛选的第一half。

完整候选journal保存法向/切向力、滑动、弹簧历史、释放能、摩擦热、塑性热及原能量账。
每根仍为24更新/100真残差/2刷新Broyden；失败时可从同一父态、同一初值再尝试一次
原modified-Newton，单次上限24/100不变，且不得绕过本阶段总墙钟预算。
macro/halves预测分别按最大已测根成本×1或2×1.5+30s，超过450s不运行。

本验证即使通过，也只证明首次肩接触的工程时间筛选，不宣称穿孔、沉积或实验验证。
