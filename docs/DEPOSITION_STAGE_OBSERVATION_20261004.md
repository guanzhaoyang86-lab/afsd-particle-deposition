## 观察定义及API

`scripts/deposition_stage_observer.py::observe_deposition_stages`接收：

```python
observe_deposition_stages(
    time_s, particle_id, component_id, mass_kg, position_m, plastic_strain,
    tool_origin_m, tool_rotation, eligible_ids, crossing_events,
    dx_m=..., bore_width_m=..., tool_radius_m=...,
    shoulder_contact=None, shoulder_contact_available=None)
```

位置/塑性/接触数组形状分别为(F,N,3)/(F,N)/(F,N)，工具位姿为(F,3)/(F,3,3)；
ID排序在所有帧固定。工具局部坐标为`(x-origin) @ rotation`。eligible ID及通过事件必须
来自独立核验的原始接受链；本模块不重新赋予初始下方材料出口资格。

返回每帧的质量/计数和穿越粒子的真实位置、高度、方孔边界距离、肩外缘余量、
肩接触样本数及穿越后的塑性增量。状态分开记录：

- 孔口中心穿越，以及当前是否仍在肩面下。
- 中心已在肩面下、方孔投影外且工具半径内。
- 横向离方孔投影至少dx/2，同时距肩外缘至少dx/2。
- 上述几何位置是否伴随实际穿越后的正塑性增量。
- 独立记录实际肩接触，以及名义dx/2半径是否全部在肩面下。

dx/2保护带仅用于分辨率尺度的观察，不能解释为空间收敛、完整粒子支撑或新接触边界。
不把“名义半径全在肩下”与罚函数肩接触硬绑成同一门槛，因为有效接触可以有允许范围内的穿透。
负塑性增量原样输出，不截为零。缺少接触数组标为不可用，不能把缺失当成实测零。

连续多个真实帧的肩外状态可报告采样持续时长，但不能证明帧间没有返回孔内。
模块始终不自动宣告完整沉积；粘接、稳定通量、有限域适用性及空间/时间敏感性仍需独立证据。
