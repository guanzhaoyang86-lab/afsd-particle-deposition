# 有限工具远场数值域扩展：独立验证协议

触发证据：`outputs/deposition_campaign_20261007/cost_v1/manifest.json`。
新1381粒子几何的首次未收敛成本map在旧可见性数值域检查处失败：
`COORDINATE_EDGE_OR_RADIUS_SCALE_RATIO_EXCEEDS_EIGHT`。该FAIL及全部v1源保持不变。

本扩展不改变工具、粒子位置、邻域支持半径、材料/力/热方程或可见图策略。
有限工具实体包含于有限圆柱体；若整个直线段的z区间位于实际查询的z范围外，
或线段xy包围盒与轴的保守最小距离超过实际查询半径，则可独立证明该查询无交。
比较必须包含显式浮点余量；不明确的情况继续调用原近场数值域检查，仍保留
八倍尺度界和判别式舍入界。路径审计采用当次膨胀包围查询的实际半径、z界，
不能用原工具大小替代膨胀查询。

已证明远场的边仍由原partition/filter处理并必须返回无交、保留支持边；新断言
发现两者不一致时停止。没有通过删除远场粒子或支持边来改变力学/热学问题。
几何证书仍使用原固定图、全时间区间和查询预算；可见性事件仍需单独耦合求解。

- `afsd_deposition_remote_setup_20261007.py` 静态复制原evaluate：数值域函数改由

  方程逐项相同。tangent、轴向执行器、fresh-map、全前缀能量和真实穿孔规则不变。
- 新初态由独立工厂重新建立，记录 `numerical_domain_protocol`，不读入v1失败态。
- 路径及事件诊断分别静态适配数值域调用，并增加原partition/filter结果一致性断言。
- `run_afsd_deposition_stage_remote_20261007.py` 是v1驱动静态适配；仅换新模块入口
  与测试/收据绑定，预算、比较阈值和同父状态分支控制不变，禁止运行时全局重绑定。
