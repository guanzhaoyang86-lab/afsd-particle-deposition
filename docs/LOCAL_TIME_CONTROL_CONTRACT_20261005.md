# 有界局部时间控制诊断（运行前登记，2026-10-05）

本实验检验数值时间分辨率，不授予沉积、论文验证或过程接受资格。
旧 ramp 诊断及 FAIL 原样保留。本实验复用相同 PySPH、918 点、独立热态
QS 物理模型、20 ms 速度启动、材料、接触、热反馈和所有原始门槛。
没有质量/模量/时间缩放，没有状态清零，没有参数拟合或负耗散裁剪。

起点是旧细支 3 ms 的未接受诊断状态：
`outputs/ramped_hot_startup_20261005/v1/chunk_003/fine/step_004/NOT_RESTARTABLE_candidate.npz`，
SHA256 `43b2957db88cb3db23f41dadd4a0b6a9c17f3b73aa92ebb4741f51b4ff03775f`。
保留从独立 t=0 开始的全部能量、接触、运动和观察历史。
旧 chunk_003 读回 PASS 支持复用该诊断父状态，不能使其变成接受态。
旧 chunk_004 的时间比较 FAIL、取证和读回一起绑定，不能覆盖或重新判定。

## 局部控制

目标从实际浮点起时刻 0.003000000000000001 s 推进 0.0005 s。
每次从同一个直接父状态独立求一个整步、两个半步；第二半步只接第一半步。
整步候选为 250、125、62.5 us，半步为一半。最多 10 次尝试、30 个主线候选。
每个候选都完整求解当前物理映射；沿用原来的有界 Broyden/同父 Newton 回退。
不插值自由粒子、不预测并强制触及接触面、不使用旧平均速度作为精确事件定位器。
不同步网格含各自分段边界路径误差；不声称子步内边界路径完全相同。

原始力、能量（包含从 t=0 的全前缀）、热、密度、几何、路径和标量等价检查全部保持。
时间比较使用原 post.compare 与全部 918 ID 的 local_compare，且穿越 ID 必须相同。
全局位置限 .01*dx、温度 .5 K、应力相对 .1、塑性相对 .2；局部位置 5 um、
温度 .5 K、应力 .1（分母底限 1 MPa）、塑性 .2（分母底限 1e-5）。
失败整步与两半步均保留。仅时间比较失败可从原父状态减小一级；最小级失败终止。
物理门失败终止。通过时两半步只成为诊断路径；连续两次最大归一误差 <= .25
才允许增大一级，最高 250 us。到终点、尝试耗尽或预算耗尽均停止，不无限二分。

## 必须独立复核

主线完成仍不算诊断资格完成。另从完全相同的 3 ms 起点，以每个已通过主线半步
再次一分为二，构造独立连续轨迹（最多 32 候选），比较每一个主线半步的共同终点。
沿用全部上述物理和时间门。首个失败终止复核；预算不足记 NOT_QUALIFIED。
不把每次局部合格误当作整个区间收敛。即使独立复核通过，也只有该 0.5 ms 区间
的时间分辨率证据，未认证完整 20 ms 启动、满速流动、长期能量一致性或空间收敛。

## 预算、冻结与读回

主线加独立复核共享实际受监督总墙钟上限 1200 s、总候选上限 62。
每次 CLI 只跑一个主线三候选组或最多四个复核候选；预测 <=450 s，内部 <=540 s，
外部 <=600 s，并由剩余总预算进一步收紧。预估 30+1.5*N*(最大历史每候选成本+1)s；
历史下限 41.3256 s，包含失败组内已完成候选和完整阶段均摊成本，不挑选快样本。
不另开 GPU 或三工况。新的任何延伸需要另行登记和预算，不能自动绕过停止条件。

纯控制器事务、拒绝回退、浮点终点、增长、尝试数和共享预算检查须先通过。
新驱动、控制器、独立读回、合同和检查收据以及所有使用的旧输入均绑定 SHA256。
每阶段落盘 protocol、候选完整字段/图/能量/接触/温度/位姿、比较、manifest、日志和
supervision；独立 saved-only 读回通过后才能使用诊断父状态进入下一阶段。
读回 PASS 可以表示失败记录一致，必须另外读取时间比较和资格字段。
所有 checkpoint 保持 accepted=false、restart_allowed=false，不发布 accepted.npz。
