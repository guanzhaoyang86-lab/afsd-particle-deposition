# 独立准静态端点功与材料储能审计

2026-10-04；分类：代数推导和独立材料点检查，**没有运行 AFSD**。
依据为本仓库 `material.update`、`mechanics.volumetric_energy`、
`quasistatic_contact.evaluate` 和事前 `HOT_QUASISTATIC_PROCESS_CONTRACT_20261004.md`。
下述恒等式说明如何记账，不证明 Jaumann 模型存在有限应变自由能。

## 1. 端点离散量

逐粒子记 `H=dt L=D(x1,rho1)u`，`c=tr(H)`，
`E=dev(sym(H))`，`Q=exp(skew(H)/2)`，`R=Q Q`，`A=Q E Q^T`。
现有更新是 `S_trial=R S0 R^T+2G A`，然后径向返回得到 `S1, dep`。
`V0=m/rho0`、`V1=m/rho1`，此处 rho0 表示本步起点密度；
参考密度另记 `rho_ref`。`q1=sqrt(3/2 S1:S1)`。

机械端点功是 `Wmat=sum V1*(S1-p1 I):H`，绝不能把 half-rotated A
代入空间虚功后声称仍是同一内力的功。配对检查为
`Epair=sum(f_int dot u)+Wmat`，应在事前严格虚功门槛内。

## 2. 偏应力账：返回诊断不能再加一次

定义：

```
e0 = S0:S0/(4G)
e1 = S1:S1/(4G)
delta_Udev = V1*e1 - V0*e0
Qplastic = V1*q1*dep
D_BE_dev = V1*||S1-R S0 R^T||^2/(4G)
E_spin = V1*S1:(E-A)
E_measure = -(V1-V0)*e0
Wdev = V1*S1:E
```

逐粒子精确恒等式（仅舍入误差）为

```
Wdev - delta_Udev - Qplastic
  = D_BE_dev + E_spin + E_measure.
```

`D_BE_dev>=0` 是端点积分的 BE 弹性离散耗散；它不是材料热。
`E_spin` 和 `E_measure` 均须保留符号，分别来自应力更新的半步旋转与
空间端点功不一致、当前体积储能权重变化。它们不是可随意补热的耗散。

`material.update` 返回的 `D_return=V1*1.5G dep^2` 另有精确含义：

```
V1*(e_trial-e1) = Qplastic + D_return.
```

这是从弹性试应力到返回应力的储能减少分解；它不是上面端点功式之外
另一个应该加入的耗散。把 `D_return` 与 `D_BE_dev` 同时从端点功扣掉，
会重复记账。保留 `D_return` 字段用于原有材料更新审计，但不要把它加热，
也不要用它消除原始全局误差。

## 3. 体积账：密度 BE 与当前体积功有一个额外有符号项

本合同 `rho1=rho0/(1+c)` 给出 `V1=V0*(1+c)`，要求 `1+c>0`。
令 `Vref=m/rho_ref`，`p1=K*(rho1/rho_ref-1)`。

```
delta_Uvol = m*[volumetric_energy(rho1)-volumetric_energy(rho0)]
Wvol = -V1*p1*c
D_BE_vol = -p1*(V1-V0)-delta_Uvol
         = K*Vref*[log(1+c)-1+1/(1+c)] >= 0
E_rhoBE = -p1*(V1-V0)*c
Wvol-delta_Uvol = D_BE_vol+E_rhoBE
```

`D_BE_vol` 是以真实体积增量计算的凸储能 BE 项。
`E_rhoBE` 来自密度 BE 闭合下 `V1*c != V1-V0`，必须原样报告；
它不是数值舍入，也不能冠名非负耗散。极小 c 时不要用相减造成的舍入
符号判断来裁零；可另外给稳定级数求值和舍入界，原始值仍应保存。

故每粒子材料原始储能缺口为

```
E_material_raw = Wdev+Wvol-delta_Udev-delta_Uvol-Qplastic
              = D_BE_dev+D_BE_vol+E_spin+E_measure+E_rhoBE.
```

右侧减尽后接近零，只证明代码实现了指定离散代数，不证明左侧物理能量
缺口可忽略，更不证明有限应变闭循环问题被解决。

## 4. 与接触、执行器及热的合并

`quasistatic_contact` 已返回材料端功、工体坐标有限壁位移功、
法向/切向簧储能、真实滑移耗散 `Dslide`、切向 BE 耗散 `Dtan_alg`、
投影/离开接触释放能 `Erelease`，以及原始法向误差
`En=delta_Un+Wnormal_relative`。后两个算法/释放项不自动进入热源。
`En` 有符号，不能裁掉负数。

令 `R` 在约束轴等于 `-(f_int+f_contact)`，自由轴为零。
`Wact=sum R dot u`；`Wwall` 直接用该接触模块实际返回的有符号壁位移功，
不混入另一套转矩乘转角路径积分。`Wext=Wact+Wwall`；
`Wres=sum u dot (f_int+f_contact+R)`。
在同一候选上应有

```
E_global_raw = Wext-delta_Ucontact-delta_Udev-delta_Uvol-Qplastic-Dslide
             = E_material_raw+Dtan_alg+Erelease-En+Wres-Epair.
```

应逐项输出此式的原始量及离散恒等式误差。全局标量允许正负抵消，因此
另外保存逐粒子/逐接触面的绝对缺口总和，避免用局部抵消冒充良好精度。

热图只吸收 `chi*Qplastic` 和材料热分配比例乘 `Dslide`，外加热库交换。
合并机械和热总能量时，已经计入温升的这些热源不可再作为独立能量重复相加。
FKS 的应变硬化没有另建储能函数；把塑性功按 chi 分热仍是声明过的近似。

## 5. 对事前 5%+1e-7 J 门槛的判断

代数恒等式容差和物理能量缺口门槛必须分开。
如果合同门槛用于原始势功/材料储能误差，那么不能先扣除算法耗散，
再以剩余接近零宣布物理账通过。这会改变事前门槛。
至少保留 `energy_raw_screen` 与 `discrete_identity_check` 两个状态。
法向功误差、材料原始缺口及切向算法/释放能都应进入原始精度观察；
不得用热库吞吐量、绝对背景温度内能或返回诊断人为放大机械功分母。

原先仅有热库交换的零位移候选可以通过代数和热账，但没有输运价值。
一个力根通过而原始能量门槛失败的候选应保持 rejected。
初始零应力、无塑性、无自旋、等体积的一步满足
`Wdev=2*delta_Udev`：原始缺口恰为该步端点功的 50%。
这不是应力实现错误，而是新端点功离散本身的限制；绝对 1e-7 J 项
可能容许非常小的步，但不能因此声称相对精度良好。

### 接受范围和绝对容差限制

只有 03 的 raw/scale 低于 5%。其余五个接受步均依赖绝对 1e-7 J 项，
且绝对项占其完整阈值的 45.44%–90.19%。因此准确说法是“通过已声明的
混合绝对/相对逐步筛选”，**不能说每步能量相对误差小于 5%**。
01 的 raw/scale=33.33%，相对于该步真实执行器端点输入功则约为 50%。
