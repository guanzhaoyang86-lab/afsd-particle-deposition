## 最小集成范围与实际调用

- `coupled_solver.IntegratedSolver(SolidSolver)`：复用原粒子、NNPS、材料、HostLeapfrog；增加整步原子回滚、源/参数匹配的接受checkpoint、有限feature储能切换检查和完整账。
- `coupled_boundary.evaluate_boundary`：连接原`contact_rows`/`contact_kick.kick`/`axial_actuator.control`；反力在同一kick求解，不在接触后覆盖自由速度。
- `coupled_thermal.advance_thermal`：原成对导热/temperature_step；摩擦热只加入一次；塑性、接触导热、壁散热及未热化功独立记录。
- `run_coupled_afsd.py`：统一配置/成本/运行/输出；`run_coupled_short_window.py`仅注册可负担终时，不改变物理。
- `inspect_coupled_afsd.py`：独立从已存数组/子区间重算；不调用被测力学/接触/热函数生成答案。

实际每步次序（不是按函数名猜测）：

```text
接受态 → 半漂移 → 更新3D邻域/corrected速度梯度L
→ Jaumann/J2/FKS(T_old) → 中点应力的伴随内力
→ 实际接触面 + event-aware多面kick，内联z-only执行器反力
→ 原始径向核成对导热 + 塑性热 + raw摩擦热 + 接触导热
→ 速度/密度kick → 半漂移 → 几何/功/热/finite检查 → 接受
                                               失败 → REJECTED，恢复上一接受态
```

材料使用kick前L，空间功另用真实接触区间平均速度重算L_mid；二者不相同。
保留一阶显式材料/热分裂，不宣称整体隐式或时间功共轭已修复。详COUPLED_AFSD_CODE_REVIEW。
机械校正梯度与伴随力成对；热传导使用原始径向核，不能把Bg直接塞给正导热系数公式。
步长先由旧stable_dt给声学/法向/热预估，实际热内外行和界在thermal中再验，超界拒绝回滚；并非自动热子步。
