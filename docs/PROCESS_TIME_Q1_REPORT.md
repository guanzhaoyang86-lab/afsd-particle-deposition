```text
accepted粒子/材料/功账
  -> 给定物理时刻与独立外载
  -> trial: 从accepted计算位移增量梯度 -> 原material.update -> 配对内力
  -> 解自由DOF整体平衡修正 -> 再次trial（不提交、不累计材料状态）
  -> 收敛候选 -> commit重新核验平衡/支承/功 -> 一次接受
  -> 真正求得的坐标、应力、外载、反力、功账输出
```

各坐标方向都有n层，存在求得的横向位移；不是二维复制或全块刚化。
无pinv、稳定化、人工阻尼、质量/时间/模量缩放，原cond(M)<=1e6仍在。
