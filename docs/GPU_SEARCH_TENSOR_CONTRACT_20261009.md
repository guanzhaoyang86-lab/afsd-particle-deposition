# 卸载舍入输入的辅助导数域扩展

既有GPU续算在27.59375ms后的两半步中，第一个半步的PID1216应力尺度从64700.9Pa降至2954.2Pa，迹残留约−3.60e−10Pa；局部相对迹门槛降至2.52e−10Pa，第二半步建切线时被拒绝。物理材料更新重放与保存应力逐位相同。这不是完整通过的阶段，原失败证据保留。

本版本只扩展辅助搜索导数的数学输入域。既有物理更新的试应力为Q S Qᵀ+2Gdt R dev(D)Rᵀ，其乘积求导对有限对称S成立，不要求计算机存储的tr(S)严格接近零。新trial_direction保留全部原求导公式、形状/有限性和原对称检查，只允许原始对称S携带非零迹；不对粒子应力或输入副本作迹投影，不提高物理残差容限，不修改本构或热源。

新material_tangent仅绑定此trial_direction；塑性radial_direction及其原门槛保持不变。新GPU ProcessTrial仅替换tangent中该辅助函数的来源；evaluate、material.update、advance_candidate、全部几何/热/能量/粗细筛查仍为原函数。原源码和状态不改写。

运行资格要求：实际失败输入和制造对称非零迹弹性输入，相对原material.update的有限差分核对；原域上的数值一致性、拒绝非有限/非对称输入、不变性和静态适配检查。然后从原PASS段的相同父态重演一粗两细，对照全部三个保存终态；再从最后原PASS完整重算失败区间，原筛查全部通过后才能作为四小时长跑父态。测试和测量分别记录，不把静态检查当物理结果。

新runner的source_sha256是旧闭包加新增显式变体及组件证据，reference_sha256绑定旧历史和源转换。续算父链可以跨该已声明边界，但每一段必须有完整原格式PASS和精确父检查点绑定。新旧source map均严格核验；不覆盖旧source字节、不修改旧收据。结果仍diagnostic_only、accepted=false、restart_allowed=false、正式接受时间增量0。

组件之后的重演与恢复各按既有实测候选成本估算，保留预测450s、物理worker540s、runner600s及外层650s上限。辅助导数扩展不代表空间分辨率、材料实验或最终沉积已验证。
