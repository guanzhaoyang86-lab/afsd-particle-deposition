## 1. 已接受能量门槛不等于时间精度通过

macro 在0.5 ms的原始能量缺口4.809588 uJ，小于26.172013 uJ门槛；
halves 的累计缺口6.174787 uJ，小于27.772931 uJ门槛，两步各前缀也通过。
但同为0.5 ms时，应力相对差36.8195%、ep相对差21.7649%，
分别超过事前10%、20%。最大位置差3.292010 um、温差0.00566134 K通过。
这两个接受分支均不能被称为已经通过时间精度筛选；穿孔质量仍为0。

## 2. 应力差主要由FKS率响应体现

应力差平方的82.21%来自棒、17.79%来自基板。把每粒子张量差精确分为
应力幅值差和方向差，81.33%来自幅值、18.67%来自方向。
98.13%的应力差平方来自两边当前步均发生塑性的319个粒子。

对这319个粒子，用**各步实际材料反馈中点温度**计算原FKS。
先在粗步的ep和温度上只替换为细步rate，再依次替换ep和温度：

| 量 | 全场范数 / Pa |
| --- | ---: |
| 实际等效应力差 | 32720319.27997 |
| 只替换rate造成的屈服差 | 32714450.60472 |
| 随后替换ep的增量 | 8990.11087 |
| 随后替换材料温度的增量 | 2034.82827 |
| 实际q差减完整FKS屈服差 | 0.00000656 |

这些范数不能直接相加。只替换rate后的未解释差范数占实际q差
`0.021400%`，显示当前应力幅值差几乎完全由不同步内率状态驱动。
这不是证明FKS率律物理正确，而是确认当前实现确实在按该率律响应。
以最终温度代替材料反馈温度会得到约几百Pa表观超屈服误差；那不是该返回
算法的真正一致性检查，本报告已使用实际反馈中点温度。

## 3. DG法向载荷的时间位置存在明显分辨率效应

| 接触量 | macro | halves第1步 | halves第2步 |
| --- | ---: | ---: | ---: |
| DG法向模量总和 / N | 12.268569 | 6.428326 | 25.344558 |
| 端点罚势梯度模量总和 / N | 42.265031 | 26.228493 | 24.460623 |
| DG/端点总量比 | 0.290277 | 0.245089 | 1.036137 |
| 活动粒子-接触片数 | 16 | 16 | 16 |
| 滑移接触片数 | 15 | 8 | 6 |
| 最大穿透 / um | 6.242720 | 4.313803 | 3.736498 |

两个最终态的活动接触集合完全相同，不是“接触数不同”造成的差异。
然而macro从初始间隙跨过接触建立阶段，DG法向是有限区间力，只达到该候选
端点罚力约29%；half2已有承载初态，DG与端点载荷接近。
单片DG法向与端点法向的最大向量差分别为2.624886 N和0.223565 N。
当前求解把这个区间法向力同**端点材料应力**平衡，因此同终时应力具有
显著的有限步时间位置差异。摩擦又使用DG方向/模量，进一步改变粘滑历程。

该解释有现有状态量支持，但两种步长仍不足以把接触时间位置效应与
材料率平均、初始间隙事件、摩擦历史及空间非线性完全分离，也不足以确定收敛阶。
不能据此宣称找到了唯一原因或已可直接改某个时间因子。

能量项也体现不同历程：macro塑性功130.226727 uJ，两half合计
213.064976 uJ（1.6361倍）；摩擦滑移功分别23.048374 uJ与约8.227598 uJ。
原始总账都小，不意味着这些具体耗散渠道已达到相同解。

## 4. 是否值得再做一次h/4

建议允许**一次独立且事前登记的4×0.125 ms诊断**，继续检查每步及每个前缀
的原始能量，并比较h/2与h/4同终时差异，阈值保持不变。
其价值是增加第三档分辨率，判断应力/ep差异是否下降，不能预先称它会通过。
粗估4×17 s约68 s，1.5倍余量加30 s约132 s，落在450 s启动预测门槛内。
真实启动仍应以实际阶段成本、源冻结和驱动器合同为准。

即便近似一阶，上一档36.8%应力差缩小一半仍可能超过10%。若差异不降低、
接触或累计门槛失败，应保留失败并停止沿同一微步策略无界延长。
若短窗通过，也必须另评过程成本：0.13 s按0.125 ms需1040步；
若仍17 s/步约4.9小时，而不是一次600 s内可跑完的输运。
因此h/4是辨别路线的有界验证，不是批准现有模型生产跑至0.13 s。

## 5. 更窄的热态刚粘塑性路线仅作为后备

独立热态刚粘塑性模型可去掉偏弹性储能及其BE缺口，但这是新力学模型，
不能将当前S或速度清零后拼接时序。它仍须求三维材料运动、开放有限工具、
不可压/压力约束、摩擦与温度耦合；不会自动消除DG接触的时间分辨率问题。

若以 `S=2*eta*dev(D)`、`eta=Y(ep,rate,T)/(3*rate)` 对应原FKS，
低率极限有奇异性和刚区屈服问题。原FKS的1/s率地板不等于一个已验证的
有限粘度正则化；额外粘度/屈服正则化必须声明、给出单位及敏感性，不能暗中裁率。
压力约束、静止刚区、正功热、简单剪切/压缩/卸载范围、接触基准和热扩散需先验证；
再进行独立初态成本与h/h2筛选。本轮未实现、未运行这一后备模型。
