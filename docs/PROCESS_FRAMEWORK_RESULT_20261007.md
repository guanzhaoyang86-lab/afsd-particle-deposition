# 论文与实机视频参考后的框架修改

## 结论

已实现新独立热态 AFSD 过程框架：分阶段机器指令、完整行程域/库存检查、
统一步内工具位姿、旋转传递与分阶段沉积观察、邻域事件失败诊断，以及
有成本上限的真实粗细步验证。旧 PySPH 后端、力学/材料/热算子与验收阈值未改。
这次框架修改不代表完整沉积问题已解决；0.16 s只是配置中的过程计划。

## 论文、视频与实现之间的对应

## 主要代码与配置

- `configs/process_framework_20261007.json`：公开参数来源、热态/预结合局限与阶段安排。
- `scripts/afsd_process_motion_20261007.py`：独立轴精确积分、统一步内位姿、行程和库存。
- `scripts/afsd_process_framework_20261007.py`：真实PySPH独立初态，原算子继承，
  完整能量/穿孔历史，按ID固定质量、初始位置、材料/示踪和执行器身份。
- `scripts/afsd_process_observer_20261007.py`：材料实际角速度、孔壁扭矩、分阶段质量。
- `scripts/visible_support_events_20261007.py`：有限采样/二分的几何事件诊断；不替代连续证书。
- `scripts/run_afsd_process_framework_20261007.py`：组件收据→成本→独立粗细步启动探针。
- `scripts/run_afsd_process_contact_window_20261007.py`：从已核对的同一3 ms诊断父态
  做局部接触时间细化，完整继承历史，不把失败旧候选或旧342点结果接入。

新程序命令预算为0.16 s、0.75转、送料0.2756 mm、走刀0.2332 mm。
以上是执行器/工具命令积分，**不是材料位移或已执行结果**。
2h=1.3 mm边缘缓冲是域预算；仍须单独做空间分辨率与域敏感性验证。

## 实际验证

1. 49项组件测试通过：17项机器程序/域预算、16项真实PySPH状态/身份、
   9项可见邻域事件、7项观察。收据 `outputs/process_framework_20261007/components_v1.json`。
   原状态审查曾发现逐粒子质量重分配和执行器身份改变未及时阻挡，已修复并保留原失败日志。
2. 真正残差/切线成本测量通过：1350粒子、2825自由度。首测完整残差约0.246 s，
   切线+线性计算约2.313 s，峰值工作集约1.06 GB；不是稳态沉积速度估计。
3. `run_v1`：0–3 ms，500/250 μs两分辨率、6粗+12细候选、6组比较通过。
   墙时56.196 s；但此时接触力/棒料转动仍为零，属于热态未接触启动检查。
4. `run_v2`：0–3.5 ms，21候选，墙时93.137 s。首次接触附近出现真实棒料转动，
   但末组时间比较失败：全局应力差13.354%、塑性差97.155%，局部比较也未通过。
   当时细分辨率候选的非执行器棒料质量加权角速度约0.686 rad/s，工具步均角速度
   2.383 rad/s，孔壁材料扭矩约0.003943 N m。**这些是未通过时间比较的候选量，
   不能当作可信定量物理解或沉积验证。**没有新材料穿孔/肩下铺展。

5. `contact_window_v1`：从同一个3 ms父态出发，125/62.5 μs对照。
   3.125 ms处全局应力差3.103%已通过，但最大局部差15.270%仍失败；
   原标准10%未放宽。墙时70.201 s，6个候选；保留失败证据。
6. `contact_window_v2`：同父态62.5/31.25 μs对照，只检验3–3.125 ms。
   2粗+4细候选、两组比较全部通过，墙时44.475 s，exit 0。
   末态全局应力差1.381%、最大局部差6.802%；质量、接触/路径、热/能量、
   全前缀及穿孔ID检查均通过。此处材料已出现接触驱动的弹性转动：
   非执行器棒料质量加权角速度0.188 rad/s，工具步均2.042 rad/s，孔壁扭矩
   0.001040 N m。等效塑性应变仍为0，穿孔/肩下新增质量均为0。
   这验证早期接触接线和局部时间精度，不验证塑性沉积或整段工况。

最终另做保存证据完整性读回：6个成本/探针阶段、51份候选checkpoint全部
通过来源/输出哈希、真实数组身份、状态与完整程序历史核对；记录在
`outputs/process_framework_20261007/verification_v1.json`。读回没有执行新方程。
所有新短探针保持 `accepted=false/restart_allowed=false`；旧正式接受状态不变。

## 运行入口和当前能力边界

在项目根目录使用既有环境；输出目录必须新建：

```powershell
& '.envs/pysph/python.exe' -B scripts/check_afsd_process_framework_20261007.py --output outputs/process_framework_20261007/components_new.json
& '.envs/pysph/python.exe' -B scripts/run_afsd_process_framework_20261007.py --stage cost --output outputs/process_framework_20261007/run_new --checks outputs/process_framework_20261007/components_new.json
& '.envs/pysph/python.exe' -B scripts/run_afsd_process_framework_20261007.py --stage probe --output outputs/process_framework_20261007/run_new --checks outputs/process_framework_20261007/components_new.json --end-time 0.003
```

当前启动诊断入口500/250 μs、粗细候选总数≤64，只覆盖最初至10.5 ms；它不会
自动执行20 ms后的送料阶段，也不会后台启动完整0.16 s。阶段运动/送料接口已有
组件验证，完整受载多阶段过程尚未验证。每阶段先估计≤450 s，内部540/外部600 s。

仍待解决：接触后的塑性阶段时间精度、遮挡/再可见事件的完整耦合重新求解、冷态加热与
工具抬升、持续补料、初始预结合近似及材料/空间/实验验证。不得靠改变输出标签、
预设自由材料轨迹、放宽旧门槛或延长一个已失败的任务来宣称形成沉积。
