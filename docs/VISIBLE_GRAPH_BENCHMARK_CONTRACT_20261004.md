# 统一可见邻域图：独立算子制造基准（运行前）

本合同只登记组件验证，不运行 AFSD、不改变已接受状态、不改任何冻结 src 或旧测试。活动基础仍是固定 PySPH 三维 NNPS；新 `scripts/visible_support.py` 过滤同一原始 i/j/g，制造基准统一将该子图交给现有 `_geometry`、`internal_force`、`pair_conductance` 和 `advance_implicit_thermal`。不接受只过滤内力或只过滤热学。

接口为 `filter_visible_support(x,i,j,g,pose,p,particle_ids)`，返回 `i/j/g`、保留/删除原始边索引、严格遮挡/舍入不确定分类及指纹。这里采用严格实体内部正长度即过滤，加固定舍入界保守分类；原 1 nm 拒绝守卫仍为独立历史检查，不能作为新图容许穿透长度。过滤没有标签、应力、温度或希望流动方向输入。

制造几何采用两个等体积立方体，单位米：第一块 x=[0.1,0.9] mm，第二块 x=[1.5,2.3] mm；两块 y=[−0.4,0.4] mm，z=[0.8,1.6] mm。工具方孔宽 2 mm、半径 1.45 mm、z=[0,2.4] mm。第一块在孔内，第二块在圆柱外；所有跨块直线都穿过工具实体，同块直线均不穿实体。此制造工具和材料参数不是论文标定值或生产参数。

每块分别用 3³ 与 5³ 个端点格点，构成 54/250 粒子的同物域两分辨率。三维梯形体积权重保证两分辨率物理体积、总质量相同；rho=2700 kg/m³，h=1.7×间距。该 h 比例仅用于制造基准，实际 AFSD 的 h 不在此修改。导热 k=150 W/(m K)，cp=900 J/(kg K)，BE 热步长 0.2 ms，固相测试温域 [273,900) K。

运行前登记以下检查；任何失败保留原始值和 FAIL，不改阈值追通过：

1. 两分辨率的 raw NNPS 均必须存在跨块边；过滤结果必须恰好删除全部跨块边，保留全部同块边。i/j/g 原始行索引一致且无重排、漏配；过滤后的实际图再经严格几何判定不得有实体穿边。
2. 全 3D 非对角仿射速度场的修正梯度逐点再现，最大 Frobenius 误差 ≤1e−10 s⁻¹。平移梯度 ≤1e−12 s⁻¹；非轴向刚体转动的梯度及对称应变率误差 ≤1e−10 s⁻¹。
3. 非均匀对称应力配对内力检查总力、总力矩与虚功。绝对容差分别 1e−12 N、1e−14 N m、1e−12 W，另加对应绝对项尺度的 1e−10 相对容差。检查使用同一保留图、体积与修正矩阵，无外加残差力。
4. 只改变孔内块速度或应力时，外块直接速度梯度与内力改变量必须为精确零。原始未过滤图必须给出非零耦合，避免空图或从未相邻的空洞检查。热图跨块系数数量必须为零；两侧分别均温 400/500 K 时，各侧温度误差 ≤1e−10 K，原始图则应有可测温差交换（最大温变 >1e−5 K）。
5. 每块内部非均匀温度、给定非负体积热源时，BE 隐式热解温度有限且位于既定固相域，每块和整体容量温增须等于各自给定入热，绝对误差 ≤1e−12 J+入热绝对量的1e−10；保存有符号账，不截温度或填补残差。
6. 将坐标、速度、应力及工具一起作任意非轴向三维刚体旋转和平移，保留/删除边的 ID 集合不变。梯度、内力的旋转协变误差 ≤1e−10×相应非零尺度+1e−12（SI）；NNPS 原始顺序可能不同，按 i/j 对核对同一边。
7. 两分辨率都评估独立解析二次速度场：每块以自身中心为坐标原点，v=(1000 ξx²,1000 ξy²,1000 ξz²) m/s，解析梯度对角为2000 ξ，非对角为0。报告全粒子体积加权梯度 RMS 与边界/内部误差；细分辨率 RMS 必须 <0.8×粗分辨率 RMS。这只证明所测导数误差下降，不声称加载位移、应力、沉积或渐近收敛阶已验证。
8. 另用 x=0.9/1.5 mm 两个各3×3的 y-z 点平面制造支撑退化：原图须为满秩三维支撑，过滤后每侧为二维。现有修正必须显式抛出退化/病态错误；不许伪逆、增加虚假邻点、降低条件数门槛或调质量/模量绕过。

执行脚本为 `scripts/check_visible_support_operators.py`，合同和实现源 SHA256 在运行前保存到新证据目录，运行后逐一核对未变化；记录命令、退出码、各原始误差、成本及 PASS/FAIL。组件不调用新/旧 AFSD trial.evaluate，不制造新接受状态。

这些检查不能消除自由表面载荷一致性、hourglass/拉伸稳定性、邻域切换的非光滑、有限步功误差、空间分辨率需求、材料低率或热态 QS 假设风险。同一固定图上的动量与虚功代数恒等不等于图随运动改变时的全过程能量验证。真实失败候选的新旧图响应由单独诊断处理，不能由本制造基准自动接受。
