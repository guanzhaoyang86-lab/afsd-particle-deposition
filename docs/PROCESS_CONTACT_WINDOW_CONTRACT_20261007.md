# 3.0–3.5 ms 接触起始局部诊断窗口

本契约只允许从 `run_v1/probe/fine/step_012/NOT_RESTARTABLE_candidate.npz`
的已核验 **3.0 ms 诊断前缀**建立一对独立局部粗细分支。该文件仍不可正式重启；
这是此窗口限定的诊断使用许可，不改变其 `classification`、`diagnostic_only=true`、
`accepted=false`、`restart_allowed=false`，不连接旧 342 粒子正式接受历史。

选择父态要求 `run_v1` 短窗口 manifest 为 PASS，6 个时间比较均通过，监督进程退出0，
manifest/log 哈希匹配，全部源与输出 artifact 哈希仍匹配。父态应为独立1350粒子
框架第12步、3.0 ms，完整机器指令、能量、穿孔及材料历史保留，不重新初始化。
两个新分支读取同一个确切文件和 SHA256。不能以 `run_v2` 的失败候选为物理父态。

默认局部窗口粗步125 us、细步62.5 us，粗4步/细8步，到3.5 ms。CLI只允许正的
有限步长和有界pair数；总新候选不超过64、程序阶段边界不可跨步、终点不可超出
已声明机器程序。它只诊断这个局部父态附近的时间误差，不证明0–3 ms前缀已经收敛，
不外推到完整0.16 s过程。

复用冻结的 `run_afsd_process_framework_20261007.complete_candidate`，保留全部
新鲜力/热/材料/质量/接触/完整前缀能量门槛，标量与批量等价、连续接触壳、旧整路径
支持边证书及可见性失败事件报告。每一对等时端点继续用原 `post.compare`、
`event.local_compare` 的全部粒子与原阈值，并要求穿孔 ID 一致。不得删边、放宽
应力/塑性误差、裁剪温度或给自由材料预设转动。任何门槛失败立即保留证据并停止。

`run_v2` 3.5 ms已失败的时间比较仍是 FAIL；只允许使用其实际候选执行时间作为
性能证据。预算为 `30 + 1.5 * (3*pairs) * max_measured_candidate_wall_s`，预算超过
450 s不启动；内部540 s、外部600 s、CPU单线程。每一步也检查剩余预算。新输出目录
不覆盖旧收据。窗口所有输出始终不可正式重启，正式接受步数/新增接受时间均为零。

默认窗口是本轮最后局部验证：即使仍失败，也应报告未解决的起始接触时间误差，
不能据此认定沉积已形成。真实角速度/扭矩属于接触响应观察；离肩几何留存候选
不是冶金结合或已验证稳定沉积。
