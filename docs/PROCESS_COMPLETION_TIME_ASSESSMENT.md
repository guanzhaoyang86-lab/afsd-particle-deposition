## 决策摘要

1. 已完成的Anderson是同一五场映射的求根改进，不是已经获得过程尺度可用步长。
   其4个50ns接受阶段证明可连续短步；不证明可把dt增至毫秒或删除惯性。
2. 应停止把更多同尺度短跑作为主要进度。优先做一个**保留真实质量/惯性的过程步接口**，
   联合解决更新几何接触、结构柔度、材料时间积分和隐式热；不重新搭后端。
3. 如果完整启动过程对用户不重要，独立的热态准静态过程变体可能更贴合工程近似目标，
   但必须新命名、新初始化，并明确只重构该初态之后的过程，不能重解释当前动态checkpoint。
   本文只给方案，不自动切换模型或授予生产资格。
4. 当前条件下，**不能诚实承诺再修几个局部事件就能完成AFSD沉积**。
   时间推进与孔口/入口是必须相交的两条工作；仅有任一条的组件PASS均不足。

## 优先可实施路线A：同设施、真实惯性、分事件整体过程步

建议新命名`PROCESS_INERTIAL_EVENT_STEP_APPROXIMATE`，先独立接口，不更改当前短步默认。
保留PA/NNPS/B及其伴随内力、ID/标签/输出、原质量/物性，采用接受态隔离的纯残差：

```text
R_m = M (v1-v0) - sum_s [h_s f_int,s + G_s^T J_s + J_ext,s + J_constraint,s]
R_x = x1-x0 - sum_s h_s v_mean,s
R_rho = rho1-rho0 + sum_s h_s rho_mid,s tr(L_s)
R_T = C (T1-T0) - Q_plastic - Q_friction_material - Q_wall - Q_pair
```

其中每个`s`是真实接受事件子区间，`J_s`含法/切接触冲量，`C_i=m_i cp_i`。
不能用整步端点平均v替换事件平均，也不能在非线性探针间累计任何材料/热历史。
宏步内L、rho、T、工具pose及normal必须来自一致子区间构形。
若用中点连续式对rho积分，应保留与现有密度闭合的一致离散；上式是接口概念，
不是本文已实现/验证的离散密度算法。

### A1 整体结构响应，不把局部P/m当宏步柔度

在光滑、固定接触分支和中点运动学下，速度Newton块至少包含
`A = M + h^2 K_t/4 + rate/thermal/geometric derivatives`，其中`K_t=-df_int/dx`。
设Z选择真实自由自由度，接触速度映射为G；约束后冲量切线响应形式为
`G Z (Z^T A Z)^(-1) Z^T G^T`，中点速度响应另带相应1/2系数。
它包括粒子间弹塑性耦合及多面交叉项；不是每面独立质量限幅。
这里是光滑局部线性化，不是在非线性/切换时强称精确effective mass。
应先以独立弹簧-多接触块验证方向导数和约束反力，然后才接真实SPH。

现有Anderson保留为短步基线和可能的全局化辅助手段；不是要求删除已有工作。
不建议用每自由度完整`UpdatedTrial.evaluate`有限差分构造dense Jacobian：342点五场有
3762标量未知量，单trial约4s，一列一trial的装配显然不在600s内；这只是成本下界推断。
先利用已知配对算子/局部材料切线组装或方向导数，方向导数一致性须独立核验。
没有切线成本数据前不承诺大步比当前更快。

### A2 热学取消显式稳定界，不取消热准确性

同一径向pair系数`k_ij>=0`形成图Laplacian H；墙面导热D为非负对角，
在固定子区间系数下，可独立实现后向Euler：

```text
(C + h H + h D) T1 = C T0 + Qplastic + Qfriction_material + h D Twall
```

保留真实raw摩擦Q和塑性热分配，不加return诊断或机械残差热。
矩阵正对角、非正非对角，C正；该代数结构给导热方向和正性检查，不能取代实际测试。
内部pair热成对抵消，wall热必须按同一T1时间层记账；材料候选T依然与热解耦合迭代。
后向Euler是**明确的一阶热积分变体**，不是暗改Table 1或原显式接口；同终时细化检验耗散/误差。
温度域若不合法仍失败，不能将隐式解截回room/melt。

### A3 本构和几何事件决定准确性步，不再只用声学CFL

- 用独立非零初应力刚转、非共轴加载、跨屈服/卸载/热软化曲线确认材料分段误差；
  每事件步从同史一次更新。当前Jaumann自由能问题另记，不声称减dt必修复它。
- 正常接触创建/消失、孔口棱边、滑移过零、执行器程序切换必须对应实际事件几何；
  子区间`Q=-Jt·u_mid`、法向势能变化与刚体功同一几何，禁止feature消失时丢失弹簧能。
- 求根容限与时间误差分开；先同一终时的h/h2制造动态-接触-热联合基准，
  再一次受预算约束的真实短窗比较。只要成本或守卫不合格，就STOP而非重复调粒子参数。
- 隐式中点对线性振子无条件稳定但相位`2 atan(omega h/2)`不等于`omega h`；
  若初始高频预压能量仍重要，不能跨过未解析周期后称启动物理正确。

这一路线不是一行改dt；它是有限、明确的新数值接口研发。
如以后选HHT/广义alpha高频耗散，必须单独命名并独立报告算法能量损失，不能默认打开或转为热。
本文不选用数值阻尼，也不建议用它抹除现有初态的动能。
