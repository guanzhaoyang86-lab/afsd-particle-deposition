# 可见支持边事件路由（2026-10-07）

本次新增只读几何诊断模块，不修改旧求解器、不重新接受旧失败候选，也不把事件定位当成物理积分。它使新过程框架能明确识别“邻域被工具遮挡后释放”的情况，防止把这种失败继续当成几何查询不足或仅需延长总时长。

## 故障与受限实现

旧 `visible_quasistatic.py` 用候选终点筛选出的同一支持图装配密度/校正、材料梯度、配对力与热。`visible_tight_path_candidate.py` 随后要求该终点保留图在整个步长内均不穿过工具实体。如果一条边在起点被遮挡、终点可见，终点图会在整步使用一条起点无效的边；旧整路径证书据此正确拒绝。只放宽相交长度、删除报错边，或增加总模拟时长均不是已验证的解决方案。

新增 `scripts/visible_support_events_20261007.py` 提供：

```python
audit_visibility_events(x0, x1, i, j, pose0, pose1, p, particle_ids,
                        sample_intervals=16,
                        fraction_tolerance=2.**-30,
                        maximum_evaluations=256)
```

它复用冻结的严格实体相交与舍入扩张筛选策略、数值域检查、实际世界坐标弦线及最短 SO(3) 工具旋转。16 等分采样发现相邻采样点之间的策略变化后，二分定位异状态区间。所有长度用米；时间分数为无量纲。分数精度只是诊断定位精度，不是物理穿透容差，不代表真实轨迹或实验时间精度。

- `endpoint_changed_edges`：端点状态变化的原始边索引、持久 PID 和严格相交长度。
- `changed_edges` / `transition_brackets`：采样发现的变化及定位区间，包括端点相同但中间被遮挡的情况。
- `requires_resolve`：观察到变化或几何不确定时为真。
- `acceptance_allowed`：恒为假；本模块没有物理接受权限。
- `proposed_intervals`：仅供重新求解器安排工作的分段建议，全部标记未求解、未认证。

没有观察到变化时，状态仍为 `NO_OBSERVED_EVENT_REQUIRES_WHOLE_PATH_CERTIFICATE`，必须执行原有整路径证书。有限采样和异状态二分都不能证明没有隐藏事件，也不能证明括区间只有一次事件。输入只覆盖调用者提供的粒子对，不能自行发现 NNPS 支持半径进入/退出事件。数值域、采样内重合粒子或预算失败均返回不确定，不能变为 PASS。

## 新过程框架的安全接入点

候选整路径证书失败时，可把该候选的原始或保留边传入本模块，将诊断写进失败报告。所有输入均不修改，零力学/材料/热/NNPS求值，零删边。

实际解除阻塞仍需要新的、独立命名的事件积分器：从最后接受状态重新求解物理子步；统一定义每段的密度、校正、材料梯度、配对力与导热支持图；沿新求解路径重新定位事件；继续通过质量、接触、整步能量历史、整路径和同父粗细步核对。不能直接用存档弦线插值点作为接受态，不能只把一条边从路径检查中删掉，也不能直接重启未接受粗网格参考态。本模块没有实现这部分，不宣称当前 62.8 ms 故障已修复。
