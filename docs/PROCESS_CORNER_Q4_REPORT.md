# Q4 双壁接触工程近似报告（2026-10-01）

## 结论与范围

新增并实际运行三维相交双刚壁的**无摩擦准静态制造基准**。四组均到同一程序
终时0.2s，交错卸载时先X脱离、Y继续承载，再Y脱离。不是AFSD推进了0.2s。
27个真实三维材料点共用一个材料状态；18接触行对应15个粒子，公共边的3个粒子
各有两个feature，不复制质量、不覆盖另一面的力。只约束三个零坐标面的法向，
54个永久自由分量；两壁全活动时仍求解36个自由分量。

核心回归实际 **12 PASS / 1 FAIL**。FAIL是严格的卸载ep不变检查：容限1e-12，
最大变化4.91846e-12；保留原断言、原失败和原物理，没有调参/裁剪/xfail。
按ENGINEERING_APPROX_CONTRACT，精细连续体偏差不单独阻断受限机制开发；
COMPLETE只表示制造路径完成，不表示所有科学检查通过，更不授权生产。

## 实现及调用次序

新scripts/probe_process_corner.py复用原Q3 ContactBlock、Q2 PlasticBlock、
原material.update及固定参考成对corrected算子；PySPH粒子、ID、输出沿用。
src/、旧配置、旧测试、旧输出均未改；后端PySPH固定
`1cd3dea9cfaac7d9f1bda2a2491ce4b42a31dbe5`。

实际companion次序（不是生产显式kick次序）：

    advance(请求时刻)
      → solve_candidate：共享活跃集
      → _equilibrate：施加当前活动壁法向边界，求整体受限自由子块
        → trial：从同一个accepted材料状态计算应变/应力/塑性/内力
        → tangent + reduced_correction + 有界线搜索（不提交）
      → contact_state：逐feature反力、逐壁力、支承、间隙
      → 若失去承载接触，_release_event定位首个释放并分段
      → commit：重新计算材料/平衡/逐壁功、验证metadata后统一提交
      → 保存accepted帧 → 继续剩余区间

每面功独立检查后才检查总功；相反缺陷不能抵消。整体受限切线不是逐粒子P/m。
三个方向位移/应力均实际求解，但仅固定参考小应变适用；不是有限旋转认证。
未用示踪标签受力，未规定脱离后材料轨迹，未加残差热或缩放物性。
