# 用户授权的十小时 GPU 长跑

用户2026-10-08请求“现在用gpu跑10个小时，我看看结果”。授权当前本机GPU后台
计算最多36000秒。监督器从最新完整PASS的12.037109375ms/98步接续，使用冻结
GPU双精度求解器；不修改既有源、配置、物理门槛或正式接受状态。

每段仍为一粗步+两细步，完整粗细/能量/接触/路径/身份检查后才替换续算父态。
每次预测30+4.5*最近最大候选耗时≤450s；物理worker540s、runner600s，外层
对子进程树650s上限，且始终受整个十小时单调时钟截止限制。剩余时间不足预测
加20s时提前结束，保留最后完整PASS；未完成段不得作为新父态。

沿用上一段macro dt，不自动增大。按原工况20ms和220ms边界准确截步；两细步
也必须止于同一边界。只有三候选全部过门槛且粗细时间精度不符、穿孔ID一致时，
才能从同一不变父态dt减半重试（最多8次，dt≥1e-7s）；原失败证据保留。
力根、能量、几何、CUDA、源或未知失败立即停止，不能自动放宽或绕过。

当前GPU实现限原地填充。新料首次进入肩下时保存并停止复核；达到220ms原地
填充末端也停止，不越过原“观察到塑性铺展才走刀”的条件。十小时不是沉积承诺。

所有结果仍diagnostic_only、accepted=false、restart_allowed=false、正式接受时间增量0。
progress.json持续更新已通过物理时间、当前尝试、穿孔/肩下数量质量和截止时间。
final_summary.json在退出时保存。所有候选、日志、收据均保留。

Windows单实例mutex避免重复监督；进程级SetThreadExecutionState仅防止空闲睡眠，
允许屏幕关闭，退出后释放，不改变系统电源计划。创建STOP_REQUESTED文件会停止
本监督器拥有的子进程树；不结束其他用户进程。无系统安装、外部消息或付费资源。
