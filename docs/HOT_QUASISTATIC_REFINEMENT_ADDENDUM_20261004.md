# 原始能量失败后的有界时间细分（运行前）

第一根：dt=0.5 ms，37次残差、18次Newton更新、28.693 s；自由力6.5073e-7 N
满足1.0181e-5 N，原始能量缺口58.3548 uJ超过29.5023 uJ，故REJECTED。
其中法向端点功缺口贡献51.2095 uJ；材料缺口5.5731 uJ；切向BE损失1.5723 uJ。
没有接受时间，未改门槛。可检验的下一假说是启动接触需要更细时间分辨率。

从同一独立初态重新开始一次序列，目标1 ms；不是读取拒绝候选作为历史。
每侧2 um间隙及侧面速度约(omega*1 mm+traverse)对应约60 us首次接触尺度，
先用15.625 us分辨启动，然后仅根据事前能量门槛与实际求解结果调步。
所有模型/材料/接触/热学/守恒阈值与原合同完全相同。

- 最多9个根尝试，每根最多24 Newton更新/100残差；失败也消耗尝试数。
  原实测根28.693 s，预估1.5*9*28.693+30=417.356 s <450 s；
  总540 s内部/600 s外部硬停，下一根若预估不能在剩余预算内完成则停止。
- 从15.625 us起；力/能量/几何失败步长减半，最小1 us。
  接受后若abs(raw)/limit<0.25，步长乘2，否则乘1.25；上限0.5 ms。
  最后步截到目标时间；不为通过阈值放宽物理容限或扣掉算法耗散。
- 预测仅用上一接受步实际平均速度*dt，顶端z和底层夹持覆盖为边界值；
  预测不作为输出或接受状态，完整平衡/热/接触残差重新求解。
- 每步独立保存原始能量/热账和粒子历史；失败候选永不转成checkpoint。
  只有完整验收的步计入新准静态时序，旧动态时间保持不变。

若九次尝试/预算内未达到1 ms，明确为未完成；即便达到也只是联合短时序。
