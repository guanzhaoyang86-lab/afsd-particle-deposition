# v3 距离链式离散梯度（运行前）

v2的0.5ms力根与逐步/区间能量通过，但同终时h/h2筛选失败：位置3.292um、温差
.00566K通过，应力36.8195%>10%、ep21.7649%>20%。不改变这些判定。

独立解析及v2实际候选证明，直接对整片势U做Gonzalez离散梯度，会在跨越接触启点、
同时沿平面切向移动时产生不符合该平壁几何的切向“法向力”。这虽满足功恒等式，
仍会影响停滑、应变率与率相关屈服。不能用能量恒等式代替物理解剖或时间精度检查。

v3改用链式构造：先对几何距离d构造离散梯度，再乘φ(d)=k/2*(r-d)_+²的距离割线。
前后处于同一平面分支时离散距离梯度严格为该平面法向，同时保留实际力功与势差
恒等式。原直接U-DG组件保留便于反例回放；新模型分类为
`HOT_QUASISTATIC_CHAIN_RULE_NORMAL_CONTACT_APPROXIMATE`，仍从独立初态建立历史。
这是接触力/摩擦方向的真实修改；材料、热、区间原始能量及其他门槛不变。

限制：这不是接触事件自适应积分器。若两端均在罚势壳外而中间短暂接触，端点距离
割线可能遗漏接触；严格实体扫掠仍保留，活动接触的时间分辨率仍需h/h2实测。
大曲率步、吸引离散法向、多最近点仍拒绝，不能以守能说明这些情形都正确。

v3必须重新组件测试、成本、0.5ms根、0.25+0.25ms同终时对照，原10%应力/20%ep
门槛不变。若仍未达标，可在同预算内加4×0.125ms诊断收敛趋势，不能启动未验证
长段生产。v1/v2冻结源zip和输出保留，不覆盖。单次540s内/600s外上限不变。

v3数值环境显式固定OPENBLAS_NUM_THREADS/MKL_NUM_THREADS/OMP_NUM_THREADS为1，
与旧精确回放基准一致；这是CPU线代再现约定，不是物理参数缩放或GPU/并行优化。
