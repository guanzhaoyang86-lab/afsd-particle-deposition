## 一、使用方法

1. 第一轮至少提供本文件；尽量同时附原论文PDF、SCIENTIFIC_REVIEW.md和VALIDATION_CONTRACT.md。
2. 把本文末尾“第一轮提问词”作为自己的消息发送。不要只问“有办法吗”。
3. 让GPT先区分确定事实、待核验解释及缺少的证据，不要直接大改求解器。
4. 第二轮按它明确列出的需求提供源码、测试和失败日志，再发送“第二轮提问词”。
5. GPT看不到你的本地路径；在没有实际上传或工具读取前，不能声称看过源码/论文图像。
6. 拿回建议后，仍需在本项目用独立基准与真实运行验证；建议不是已经完成的修复。

本文不指定模型版本、账号功能或承诺加速倍数。提问组织采用清晰目标、分隔背景、显式限制和验收输出；参考OpenAI官方提示词文档，链接在末尾。AFSD技术事实来自本地审查，不来自这些OpenAI文档。

### 5.2 三维应力与压力

~~~text
sigma = S - p*I
K = 2G(1+nu)/(3(1-2nu))
p = K*(rho/rho0 - 1)

rho0 = 2700 kg/m³
G = 26.3 GPa
nu = 0.33
~~~

采用Jaumann客观率、J2塑性返回和FKS。压力闭合是明示近似，不声称完全等同于参考文献所有细节。

### 5.3 FKS

已核对原PDF第6、14页图像：

~~~text
yield = H(ep) * Lambda(rate,Tstar) * Theta(Tstar)
H = a1 + a2*atan(a3*ep)
Lambda = 1 + b1*Tstar^b2*ln(rate/rate0)
Theta = 1 - (1 + exp(-c1*Tstar))^(-1/c2)
Tstar = (T-Troom)/(Tmelt-Troom)
~~~

注意1/c2作用于完整括号。

~~~text
a1 = 317.6 MPa
a2 = 1 MPa
a3 = 70
b1 = 12.44
b2 = 5.65
c1 = 13
c2 = 0.01
~~~

未决项：

- Table2把b1标成MPa，但Eq.6乘法结构要求无量纲。
- 当前APPROXIMATE变体用无量纲12.44，未机械乘1e6。
- Troom=293.15K、Tmelt=855.15K、rate0=1/s仍是假设。
- 显式rate_eff=max(rate,1/s)，记录低率floor使用计数；不是已确认的论文规则。
- 温度越域/非法屈服必须失败，不静默裁温或屈服。

## 六、空间离散审查及当前修正

原始Table1解读路径的独立反例：

1. 边界邻域不完整时，刚体旋转产生伪对称梯度，相对量约0.42089。
2. 体积加权速度梯度与原应力力在不同密度时不功共轭，一例缺口约9.76%。

这些结果只针对当前代码路径及具体基准；不能据此断言作者完整程序必然同样错误。

当前增加显式APPROXIMATE变体：

~~~text
Vi = mi/rhoi
rij = xj-xi

Mi = sum_j Vj * (rij tensor grad_i Wij)
Bi = inverse(Mi)

Li = Lraw_i * Bi

Fij = Vi*Vj * (sigma_i*Bi^T + sigma_j*Bj^T) * grad_i Wij
~~~

实现位置：mechanics.corrected_operators、mechanics.internal_force及solver.evaluate。
修正梯度与伴随力必须一起使用。独立仿射、非零应力旋转、功、总线/角动量基准通过。

限制：

- 明确不是逐字Table1公式，仍需论证其与论文方法的关系。
- 奇异或条件数>1e6邻域拒绝，不伪逆兜底。
- 导热保留原径向梯度以维持方向/符号。
- 修正梯度谱稳定界、拉伸失稳及长期自由表面处理未充分验证。
- 原始路径仍保留用于审查，不应把原始反例从测试中删掉来获得全绿。

## 七、核心阻塞A：多力耦合的摩擦功/热

当前为有限解析面、罚法向力、无历史记忆的滑动正则化，非完整静粘滑。

~~~text
|Ft| = min(mu*Fn, m*|v_t_relative|/dt)
~~~

力方向按kick前相对切向速度确定。

原算法把旧速度摩擦功率直接乘dt。独立冲量基准发现：动能实际损失1J，算法却产生2J摩擦热。

现改为：

~~~text
v_mid = (v_before + v_after)/2
Q_friction = -Ft · (v_mid-v_wall)_tangent * dt
~~~

v_after包含全部内力、接触力与执行器约束。修复后孤立静壁、动壁及共转零滑移基准通过，但小耦合案例触发：

~~~text
negative midpoint friction dissipation;
coupled kick reverses contact slip
~~~

程序停止，不取abs，也不把负热裁成零。

待检验解释：孤立接触的冲量上限不保证多面接触、内力和执行器同时作用时不反向滑移。
这不是已确定根因。失败粒子ID、各分力/约束冲量、相对滑移及负功幅值尚未完整落盘，不能排除小量容限、接触切换、时序或诊断定义等替代解释。

几何另有真实缺口：

- 已增加深陷工具实体的失败保护，旋转方孔保持开放。
- 外圆、顶面、棱角接触仍不完整。
- 已有球面重叠外圆/顶面但中心未入实体、接触力仍零的反例。
- 接触点速度重建、力矩与多面一致性需要单独验证，不能只替换壁速度某一处。

## 八、核心阻塞B：本构与储能诊断

当前诊断：

~~~text
Es = sum_i Vi * (Si:Si)/(4G)
~~~

独立反例：

~~~text
m = 1 kg
rho = 2700 kg/m³
G = 26.3 GPa
S = diag(2,-1,-1) MPa
D = -I /s
初始p = 0

S:D = 0
~~~

constant-G Jaumann偏应力更新保持S不变，但体积减小。于是：

~~~text
dEs/dt = -3Es ≈ -0.063371356 J/s
独立差分结果 ≈ -0.063371261 J/s
~~~

确定事实：所用储剪切能表达与这一应力/体积更新不一致，缩小dt不能消除该反例。
未确定：必须更换本构，还是应使用一致的物理功积分内能、修正储能诊断，或采用其他闭合。

希望专家区分“诊断能量定义不适用”和“应力演化本身必须改”，不要先入为主。
合法的内能功积分与按能量残差回填假热源不同；后者禁止。

## 十一、预先冻结的数值门槛

完整定义见VALIDATION_CONTRACT；以下不是实验误差或万能物理容限。

- 核积分绝对误差1e-7；核导数相对1e-6。

- 相同物理BC下dx=.5/.25mm：整体量差<=10%、峰值ep差<=20%；两网格不等于渐近收敛。
