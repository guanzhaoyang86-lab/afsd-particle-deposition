# 输运几何解释与成本只读报告更正

真实求解器及四个接受步不变。主代理在事前合同/交流中把“原始肩面以上孔内最下层棒中心”
简写成“最下层棒中心”，会误导读者以为整根棒都在肩面上方。
实际原始有限料棒跨过z=1.5mm平面：75点初始在肩下，75点初始在肩上。
肩下那75点是初始几何，不是本轮新穿越或新沉积。

第一次独立成本脚本又错误取所有棒点的有符号最小z0-layer=-1.25mm，
导致process_feasibility.json输出负名义时间/负成本，却未拒绝。
该文件与process_feasibility.log完整保留，**该首版报告逻辑FAIL/INVALID，禁止引用其中成本和guard结论**。
它不是物理试跑，也没有改变任何粒子；真实continuation和独立四步reader均不依赖它。

修复：名义轴向尺度只对初始肩面以上的待出孔群体取最小正间隔250um；
能否跨平面按全部棒中心的最小绝对间隔250um与位移域50um比较，两侧均不可能跨越。
新增三个独立几何回归：跨平面初始几何、位移域触及一侧、无肩上群体不能产生负时间。
修复后的有效结果是process_feasibility_corrected.json；名义时间不是材料真实穿越时间预测。
