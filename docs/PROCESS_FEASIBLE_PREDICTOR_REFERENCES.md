# 可行初猜：独立解析参考与验收建议

状态：独立推导，非运行报告；本文件不将任何未运行测试计为PASS。
来源：本项目制造的三自由度对称正定弹簧系统，不来自论文材料参数。
用途：区分负法向的初始猜测与确实不存在受压固定接触平衡解。
不能据此宣称当前Q7目标存在可行解，也不验证Coulomb摩擦、塑性、热或AFSD。

## 定义与符号

全局位移 u=(x,t,q)，单位m；这里t是切向位移，不是物理时间。
刚度单位N/m，能量单位J：

```text
K = [[ 2,  1, -1],
     [ 1,  3, -1],
     [-1, -1,  2]]
E(u) = 1/2 u^T K u
g = K u = -F_internal
N = -g_x
```

x=-1规定且不变，t为规定的切向加载，q是真实自由DOF。
外力平衡时f_external=g；规定法向外力为-N，切向执行器反力为g_t。
自由DOF必须满足g_q=0，不能只满足N>=0。
切向位移只在本独立弹簧夹具中规定，不授权在AFSD自由材料上规定轨迹。

K的顺序主子式分别为2、5、7，严格正定。
消去自由DOF后的(x,t)刚度为[[3/2,1/2],[1/2,5/2]]。
因K_qq=2，固定(x,t)时自由平衡解唯一；所以本例可以严格证明有解/无解。

## 独立消元解

```text
g_q = -x-t+2q = 0
q_eq = (x+t)/2 = (t-1)/2
g_x = (3x+t)/2 = (t-3)/2
N_eq = (3-t)/2
g_t = (x+5t)/2 = (5t-1)/2
E_eq = 3/4 - t/2 + 5t^2/4
```

初态t=0、q=-1/2，N=3/2N、g_t=-1/2N、E=3/4J。
受压固定接触的可行界限是t<=3m。t=3时N=0，仅为法向可行边界，
不证明零摩擦容量接触的任意切向模式可行。

| 目标t (m) | q_eq (m) | N_eq (N) | g_t (N) | E_eq (J) | 固定受压接触 |
| --- | --- | --- | --- | --- | --- |
| 5/2 | 3/4 | 1/4 | 23/4 | 117/16 | 唯一可行平衡 |
| 3 | 1 | 0 | 7 | 21/2 | 法向边界 |
| 4 | 3/2 | -1/2 | 19/2 | 75/4 | 无可行受压平衡 |

t=4行是数学上的双边约束平衡，不是允许接受的单边接触物理状态。
实际Q7的负法向初猜并不自动满足这个线性反例的无解条件，不能套用结论。

## 为什么旧位移初猜会错误地碰到定义域保护

从初态直接施加目标t，而保留q_old=-1/2：

```text
N_guess = 3/2-t
g_q_guess = -t
g_t_guess = 3t-1/2
E_guess = 3/4-t/2+3t^2/2
delta_q_Newton = -g_q_guess/K_qq = t/2
E_guess-E_eq = t^2/4
```

在t=5/2，初猜N=-1N、自由残差g_q=-5/2N。
完整自由机械修正delta_q=5/4m后，q=3/4m、N=1/4N且自由残差为零。
初猜能量71/8J高于平衡能量117/16J，差25/16J。
这个差值只是两个算法候选之间的能量差，不能记作物理耗散或补入热量。

令q(lambda)=-1/2+lambda*t/2、0<=lambda<=1，则
N(lambda)=3/2-t+lambda*t/2。在t=5/2只有lambda>=4/5才法向可行；
lambda=1/2仍给N=-3/8N。因此“从负法向猜测出发，把修正不断减半”
不必能进入可行域，不能把初猜修复误写成只能接受小步的常规可行线搜索。
完整机械修正必须仍受有界预算、有限值与后续原接触根验收约束。

在t=4，从q_old到q_eq的整个lambda∈[0,1]线段法向都不可行。
不能通过增迭代次数、裁负法向或默许拉力把它变成PASS。

## 两个必须保留的反例

1. **只令法向非负但没有平衡。** 在t=4强行取q=2m，确实N=0，
   但g_q=1N，E=19J；不能接受。在t=5/2取q=1/2m也有N=0，
   但g_q=-1/2N。不得把“进入定义域”与“已收敛”混为一谈。
2. **真实不可行固定接触。** 在t=4唯一自由平衡q=3/2m给N=-1/2N。
   必须返回明确失败，accepted状态、时间、塑性历史和所有功账不变。
   本轮不自动把固定法向改为可开离主动集；那是另一个有独立基准的模型范围。

另建议保留旧初始化入口在t=5/2直接因负N拒绝的RED证据；
这是证明新修复捕获原错误的反例，不应删除或改判旧入口PASS。

## 力与功：独立参考

沿q_eq(t)加载时x恒定，法向外功为零；q为自由平衡，自由外功也为零。
切向执行器功是

```text
W_t(0 -> T) = integral_0^T (5t-1)/2 dt
            = 5T^2/4 - T/2
            = E_eq(T)-3/4.
```

线性反力使端点中点力乘位移的公式在此路径上精确：
W_t=(g_t(0)+g_t(T))*T/2。无需调用被测接触或功函数生成参考。

| T (m) | W_t (J) | W_normal (J) | W_free (J) | E_final-E_initial (J) |
| --- | --- | --- | --- | --- |
| 5/2 | 105/16 | 0 | 0 | 105/16 |
| 3 | 39/4 | 0 | 0 | 39/4 |
| 4 | 18（双边代数值，不允许接触接受） | 0 | 0 | 18（同左） |

本夹具没有摩擦耗散、塑性耗散或热源；这些物理量没有通过此测试验证。
初猜到终猜的改变不是额外物理过程，不进入上述外功或能量账。

## 建议先验容限和实际测试要求

这些是量级约1的float64解析弹簧夹具建议，不放宽Q7既有验收容限：

- 位移绝对误差<=1e-12m；法向/自由残差/反力绝对误差<=1e-12N。
- 能量和功绝对误差<=1e-12J，较大标量可以并用1e-12相对容限。
  依据是良态的3x3线性问题，解析有理数直接给定，不含空间或时间截断误差。
- 法向定义域的N<0保护不得改成“负数在新容限内就接受”。
  边界两侧用t=3±2^-20m检查N=∓2^-21N，远大于上述比较误差；
  t=3本身可以精确表示，但N=0通过不授予接触力学完整认证。
- 不使用被测函数生成参考q、N、E或W；测试应直接给上表常数/独立多项式。
- 验证旧可行初猜路径保持原结果；新修复只在现有初始化失败机制触发。
- 验证修复评估次数有显式上限；非有限量、奇异/病态自由切线明确失败，
  不静默pinv，不改原接触求根预算，不裁力或残差。
- 非收敛、不可行、预算耗尽均必须保持accepted完整指纹不变。
  原始失败与新失败都保留，不以“尝试次数耗尽”掩盖首次原始原因。

## 对实际源码的最小补丁边界

已只读核验原scripts/probe_process_friction_cone.py：
ConeBlock.branch先套新壁面位移、保留其他自由位移，再调用trial -> state；
state内部先调用cone_response，后构建完整contact/residual。
cone_response的负法向保护可在首次Newton迭代前抛错；
后续线搜索已有负法向探测拒绝，但它不能修复尚未进入循环的初猜。

新companion若加入可行初猜，建议必须满足：

1. 只生成候选位移；先用未裁剪的真实trial及自由机械切线求可行候选。
   受约束x/t分量不被偷偷释放，法向力仍由实际内力计算。
2. 进入原cone_response后仍走原整体法切耦合、原力/滑移/功验收和原子commit。
   初猜机械平衡不等于全部接触模式已平衡，不能绕过原contact root。
3. 所有候选从同一个accepted材料历史评估；不得将预测器或局部延续的
   中间应力/塑性状态提交为新起点而不记录物理区间。
4. 记录旧初猜负N、预测修正、原始新N、自由残差、评估数、后续root状态；
   predictor只标PREDICTOR_NOT_ACCEPTED，失败原始数组标REJECTED且不可restart。
5. 同一目标修复前后只允许“初始化方式”差异；配置/来源哈希、材料/边界/
   几何/接触容限保持一致，最终接受仍须独立读回逐粒子功账。
