## 真实集成仍需的三个接口

1. **候选到求解器。** 用候选 PA 和 `process_state_for` 提供的 ID 对齐接触/free 行构造全新 trial；重建真实 NNPS、统一可见图、修正梯度和切线。插入前后的维数不同，不能复用旧 Broyden secant。几何无交叠、初始接触状态及入口面切换必须先核验。
2. **求解器到凭据。** 外部 verifier 核对既有 force、heat、energy、geometry_overlap、NNPS、visible_support、gradient_rank、contact 八项证据文件及来源。实际 PA、接触/free 摘要、父候选、准确时间和唯一 step ID 必须匹配。回调是信任边界，本模块不会把布尔 PASS 或伪造凭据变成物理证明。
3. **开放系统能量与发布。** 本层只保存三个以 J 计的有符号来源项，不计算它们，更不计算完整累计过程残差。压力流功、执行器反力、弹性储能对流必须从同一入口控制体和能量定义推导，避免重复计入；若存在偏应力牵引也必须进入外部完整账。旧来源动量/动能只是库存记录，不能自动算成 QS 已求解惯性。`elastic_convected_energy` 不能从未求解 scratch 字段硬取数。完整能量资格通过后，runner 才能将实际 PA 与返回事务状态原子写入同一 checkpoint；诊断链必须仍标不可过程接受。

已有小域穿孔证据、旧入口协议的候选分类、旧失败和旧接受链均未改判。下一项有价值的工作是独立三维入口基准的两次真实插入与预置长棒对照，而不是把本组件测试计作持续沉积验证。
