# PAPER_SPEC — 已核对的研究基线

## 0. 来源与范围

P0 = 用户上传 `sph_simulation.pdf`：Stubblefield et al. (2023), Computational Particle Mechanics 10:1629–1643, DOI 10.1007/s40571-023-00578-x。以下 P0 页码按 PDF 从 1 开始。

这是基于全文和关键图表的研究说明，不是作者代码的恢复结果。原始/处理数据在发表时无法共享（P0 p.13，Acknowledgements）；未查到可核实的作者 SPHriction-3D 公开开源仓库。不能据此断言它永远不公开，也不能把 WeldForm 称为作者原代码。

研究目标：复现三种单层 AFSD 工况中的材料流动及示踪分布；最后输出真实三维场、持久粒子轨迹、三维查看器和与论文的对照。不能用预设旋转+径向+平移速度场替代动量/能量/材料模型求解。

## 2. 力学与热学（P0 p.5 Table 1, p.6, §3）

原文给出：密度 2700 kg/m³，剪切模量 G=26.3 GPa，泊松比 ν=0.33。热导率 k(T)、比热 Cp(T) 的函数指向参考文献 [40]，不是本文中完整给出的常数。

Table 1 包括质量守恒、动量守恒、Jaumann 偏应力率、σ=S−pI、应变率、spin、能量方程。时间积分为 leapfrog forward difference。实现必须从 Table 1 与参考文献建立完整闭合，而不是只实现 SPH 插值。

P0 p.5 Table 1 的矩阵/分量 Jaumann 项须结合 spin 的定义逐项检查，不能直接照搬任意教材的旋转符号。用预应力材料点的刚体旋转测试验证客观性。

完整实现仍需显式说明：压力闭合/EOS、塑性返回映射和等效塑性应变更新、摩擦接触、接触导热、塑性功与摩擦功转热、稳定化与时间步约束。本文没有将所有这些细节完整列出，缺失不能等于“不需要”。

## 3. 核函数（P0 p.5 Eqs.2–3）

原文称为 hyperbolic spline：

    W(s,h) = α3 * f(s)
    f(s) = s^3 - 6s + 6       0 <= s < 1
         = (2-s)^3            1 <= s < 2
         = 0                  s >= 2
    α3 = 15 / (62 π h^3)

实现建议使用标量 s = ||xi-xj||/h；这是对距离含义的实现解释，原 Eq.3 印为 (xi−xj)/h。p.5 对 h 的文字表述与物理长度/倍率可能混用，需查参考文献确定 h 与间距的关系。记录该解释，不无声沿用另一种库内核。

测试：三维积分归一化、分段连续性、s=1 与 s=2 附近导数、自项/零距离、梯度方向和支持域。核在 s=0 的径向导数行为值得专门处理；不能用大 epsilon 掩盖奇点或重叠粒子。不能把普通 cubic spline 直接称为论文核。

## 4. FKS 本构（P0 p.6 Eqs.4–8；p.14 Table 2）

从页面图像核对的形式：

    σy = H(εp) Λ(εdot,T*) Θ(T*)
    H = a1 + a2 atan(a3 εp)
    Λ = 1 + [b1 (T*)^b2] ln(εdot / εdot0)
    Θ = 1 - 1 / (1 + exp(-c1 T*))^(1/c2)
    T* = (T - Troom)/(Tmelt - Troom)

注意 Θ 的 1/c2 是整个括号的指数；不是在括号之外再乘 1/c2。

| 常数 | 原文数值 | 表中标注 |
|---|---:|---|
| a1 | 317.6 | MPa |
| a2 | 1.00 | MPa |
| a3 | 70.00 | 未列单位 |
| b1 | 12.44 | MPa（与 Eq.6 的乘法结构存在量纲疑问，未解决） |
| b2 | 5.65 | 未列单位 |
| c1 | 13.00 | 未列单位 |
| c2 | 0.01 | 未列单位 |

不要把 b1 在未核实前机械乘 10^6。Eq.6 要求 Λ 为无量纲，但原表确实给 b1 标了 MPa。保留原始事实、查 [41]，将所采用的量纲解释标为未决/已解决。不可用 Johnson–Cook 常数填进 FKS。

Troom、Tmelt、εdot0 与低/零应变率正则化、T* 超范围处理，在本文没有足够完整的数值规则。来源需补齐。默认把温度截在熔点以下、把负屈服应力剪掉并继续跑，会掩盖模型问题；应记录、告警/失败，并在需要时启用明确命名的正则化变体。

材料点测试：参考应变率、跨温度/应变率范围、零/极小应变率、卸载、塑性残差、塑性功非负、单位换算；与独立标量公式实现对照。测试适用域，不要武断要求整个未校准区间都呈单调性。

## 5. 示踪（P0 p.6 Fig.5, pp.11–12 Figs.11–12）

论文将初始处于基板上方 3–4 mm 的进料外表面与中心 SPH 点作标签，分别代表氧化物与铜丝。标签点保持与 AA6061-T6 相同的材料属性。外层 1 mm 点不代表真正解析 69 μm 厚氧化层；铜的真实碎裂也没有被解析。

必须保留 particle_id、初始坐标、material_id、tracer_type。重排不能改变标签，材料力学不能读取 tracer_type 决定运动。

局部标记带、Fig.11/12 选取的代表轨迹、Fig.8 五区统计以及 Fig.10 整段铜分布之间的精确采样程序，本文未充分展开。连续全棒着色可以另作诊断模式，但不得无声替换原局部标记协议并宣称严格复现。

## 6. 验证目标和图的位置

- p.6 Fig.4/5：三维几何组成与外部/内部示踪起始位置。
- p.7 Fig.6：五个沿沉积方向的分析区；AS 和 RS 分析区域各宽 15.88 mm，关于工具轴线居中，不一定关于沉积外形中心。精确沿程区间不能仅凭“1–5”随意等分后声称相同 ROI。
- p.9 Fig.8：实验是 AS 氧化物面积 / RS 氧化物面积；论文总体解释稳态区域偏 RS，起止区差异大。不要强迫所有区每一个实验点都小于 1（图中例如 starved 第2区点接近/略高于1）。
- p.10 Fig.10：内部铜总体偏 AS，呈弯曲富集带；RS 仍有零散铜；末端有未完全流出的聚集。
- p.11 Fig.11：外层粒子在工具参考系的路径；低进给较多绕转，高进给径向排出更强，轨迹更不规则。
- p.12 Fig.12：中心粒子螺旋向外，某些粒子未离开进料旋转范围。
- p.13：粒子运动主要集中在进料正下方；平肩面条件下，进料旋转范围外的旋转流弱。

实验面积比不能直接等同于三维标签点数比。可同时输出 R_count 和体积加权 R_volume 作为代理指标，但明确名称/权重；要与实验面积比定量对照，必须定义匹配的截面或取样投影及 ROI。分母为零应输出 undefined 与计数，而不是静默加小常数。

精确 Fig.8 数值若从图中提取，必须标为 digitized_from_figure，并记录坐标校准和读图误差。本文未提供原始 CSV。用某图调参后，不能再把同一图称为独立验证。

## 7. 坐标与 AS/RS：实施约定，不冒充作者坐标

先定义实验室工具平移 Vtool、旋转 ω、法向。几何侧别由 (ω×r)·Vtool 的符号确定（同向侧为 AS）。映射到论文画面时，必须记录轴变换。

论文轨迹用工具固定参考系；建议用只随工具平移、不共转的坐标 x'=x-Xtool(t)、v'=v-Vtool(t)，并明确这项选择。相对基板来流与实验室工具移动方向相反，不能据图中“traverse flow”箭头倒置 AS/RS。若使用共转系，须完整处理运动学/动力学变换，不能混用。
