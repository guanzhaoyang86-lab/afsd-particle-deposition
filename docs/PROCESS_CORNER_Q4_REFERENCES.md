# Q4：相交双刚壁的独立参考（运行前推导）

2026-10-01。以下参考由小应变弹性/关联 J2 和互补条件直接推导，未调用被测
contact/material 函数生成答案。本文件不授予 PASS；算例及测试的实际状态由日志
决定。参数来源是 Q2/Q3 已冻结的制造问题，不是论文实验数据或 AA6061 标定。
本轮不读新论文公式、不改材料参数、不据本参考反向调整粒子运动。

## 1. 物理问题与接触库存

初始立方体 `0<=X,Y,Z<=L`，`L=.01 m`，`A=1e-4 m^2`，`V=1e-6 m^3`；
`rho=2700 kg/m^3`，总质量 `.0027 kg`。制造材料 `E=70e9 Pa`、`nu=0`，
`G=35e9 Pa`、`K=E/3`；J2 完全塑性 `Y=90e6 Pa`，等温、无硬化。
弹性分支使用不会在此路径屈服的原基准材料，不可与 J2 结果混称。

X=0、Y=0、Z=0 各自仅法向 roller 支承。两个刚壁位于
`x=L+dx(t)` 和 `y=L+dy(t)`，法向指入材料分别为 `(-1,0,0)`、`(0,-1,0)`；
Z=L 自由。只规定壁的运动，不规定自由材料轨迹。

候选为初始 X=L、Y=L 的两个面。n3 各 9 个候选，合计 18 个接触；
共享边 X=Y=L 上有 3 个粒子，每个拥有两个独立的 feature/normal/contact_id。
因此只有 15 个不同的接触粒子，不能按 particle_id 去重成 15 个接触，或让后一个
面的力覆盖前一个面的力。永久支承后 54 个自由分量，两面全活动时剩 36 个自由分量；
其他切向分量仍由平衡求解，不将整个面或材料块刚化。

逐接触定义：`g_i=d_feature-u_normal_i>=0`，`lambda_i>=0`，
`lambda_i*g_i=0`，材料受力 `-lambda_i*e_normal`。共享粒子的两个分量受力相加。
零间隙、零反力点的 active/open 分类可以退化，但不能以分类代替力学/互补检查。

两壁共同加载：`dx=dy=-.0004*t m`，`0<=t<=.1 s`，峰位移 `-40 um`。
对称回程：两壁均以 `.0004 m/s` 回到 `.2 s` 时的零位移。
交错回程：X 壁同前；Y 壁在 `.1<=t<=.15 s` 保持 `-40 um`，随后以
`.0008 m/s` 回到 `.2 s` 时的零位移。必须保留 `.1/.15 s` 的程序拐点。
时间只定义准静态程序，不代表惯性问题已通过物理时间验证。

## 2. 独立均匀弹性参考

因 `nu=0` 且 Z 面自由，`sigma_x=E*epsilon_x`，`sigma_y=E*epsilon_y`，
`sigma_z=0`；弹性阶段两轴的均匀法向响应互不耦合。
接触时 `epsilon_x=dx/L`、`epsilon_y=dy/L`，每壁材料合力
`R_feature=A*sigma_feature`。峰值各 `-28000 N`，总储能/加载功 `1.12 J`。
对称或交错回程都可持续接触至 `.2 s`，最终位移、应力、净功均为零。
这两个回程程序没有退到正壁位移，故弹性末端的零反力不能当成严格正间隙阶段。

交错弹性程序可发现 feature 混淆、错用同一个 wall displacement、功账混加，
但 **nu=0 均匀弹性本身不能证明非零跨面耦合**。必须另有下述独立耦合矩阵
基准及 J2 加载，不能仅凭出现两个面的输出就声称正确处理耦合。

## 3. 等双轴 J2 加载：流动、残余形状与功

记 `a=.004`，`eY=Y/E=.001285714285714286`。均匀加载应力为
`sigma=diag(-s,-s,0)`，其 von Mises 应力恰为 `q=s`。
在屈服面上关联流动方向为 `n=dq/dsigma=diag(-1/2,-1/2,1)`，故

    d epsilon_p_x = -d ep/2
    d epsilon_p_y = -d ep/2
    d epsilon_p_z =  d ep

加载到峰值时 `epsilon_x=epsilon_y=-a=-Y/E-ep/2`，因此
`ep_peak=2*(a-eY)`。不可把两个单轴问题的 ep 直接分别更新后覆盖或相加到
各自独立材料状态；该结果来自共享的三维 J2 应力和一个累计 ep。

| 独立连续体量 | 公式 | 数值 |
| --- | --- | ---: |
| 初次屈服时刻 s | `.1*eY/a` | `.032142857142857143` |
| 峰值应力 Pa | `diag(-Y,-Y,0)` | `diag(-90000000,-90000000,0)` |
| 每壁峰值材料合力 N | `-A*Y` | `-9000` |
| 峰值/最终 ep | `2*(a-eY)` | `.005428571428571429` |
| 最终 epsilon_x、epsilon_y | `-a+eY` | `-.002714285714285714` |
| 最终 epsilon_z | `2*(a-eY)` | `.005428571428571429` |
| X=L、Y=L 材料面最终法向位移 m | `L*(-a+eY)` | `-.000027142857142857` |
| Z=L 材料面最终法向位移 m | `2*L*(a-eY)` | `.000054285714285714` |
| 最终每壁间隙 m | `L*(a-eY)` | `.000027142857142857` |
| 峰值弹性储能 J | `V*Y^2/E` | `.115714285714285714` |
| 总加载功 J | `2*V*(Y*a-Y^2/(2*E))` | `.604285714285714286` |
| 总弹性卸载功 J | `-V*Y^2/E` | `-.115714285714285714` |
| 最终塑性功/连续净功 J | `2*V*Y*(a-eY)` | `.488571428571428571` |

每壁连续净功为 `.244285714285714286 J`；这里的逐壁相等仅针对声明的路径，
不能写成一般接触热分配/强制均分规则。残余形状小应变迹为零，不表示已验证
有限变形的 det(F)=1 或更新密度。最终零应力、零反力是均匀连续体答案；
离散残余应力和空间不均匀性须报告，不能裁为零。

## 4. 对称/交错脱离的独立时刻

对称回程先弹性卸掉两轴压应力，没有反向塑性：两壁在
`t=.1+L*eY/.0004=.132142857142857143 s` 同时到零力。
此后材料不随两壁回零，ep/P 不再增长。

交错回程先令 X 壁回程、Y 壁保持。只因本基准 `nu=0`，弹性卸载时
`sigma_y=-Y` 保持，`sigma_x` 从 `-Y` 上升到 0；`sigma_z=0`。
设 `r=-sigma_x/Y`，`r` 从 1 递减到 0，则

    q^2 = sigma_x^2 + sigma_y^2 - sigma_x*sigma_y
        = Y^2 * (r^2-r+1) <= Y^2,   0<=r<=1.

所以这段 **没有新增塑性**，q 中途降至 `sqrt(3)/2*Y`，末端重新达到屈服面，
但保持状态没有塑性增量。X 在 `.132142857142857143 s` 释放。
X 释放后、Y 仍保持时，材料有 `sigma_x=0,sigma_y=-Y,sigma_z=0`；
X 面残余位移不随已脱离 X 壁回程。

Y 壁在 `.15 s` 开始回程，以 `.0008 m/s` 卸掉 `L*eY` 的弹性压缩，
在 `t=.15+L*eY/.0008=.166071428571428571 s` 释放。
Y 卸载时 q 从 Y 降至 0，也不增加 ep。两壁终态与对称程序相同。
两次释放之间只一个面仍承载，是检验逐 feature 活动集合与功账的关键区间。
均匀参考不能保证所有离散节点严格同时释放；实际逐节点事件和余量应保存。

这不是任意非比例加载的普遍结论。改 nu、改变卸载幅值/次序或采用有限应变后
必须重新推导，不能把这两个解析时刻硬编码进求解器。

## 5. 非零跨面塑性耦合与真实零刚度机制

在等双轴已塑性加载的光滑流动分支，nu=0 的三维法向弹性矩阵为 `E*I`，
关联完美塑性的瞬时一致切线为

    C_ep = E*[ I - (2/3)*(n tensor n) ],  n=(-1/2,-1/2,1).

对自由 Z 面消去 `d sigma_z=0` 后，两法向的切线为

    [d sigma_x]     E [ 1  -1 ] [d epsilon_x]
    [d sigma_y] =  ---[       ] [d epsilon_y].
                    2 [ -1  1 ]

跨项为 `-E/2`，不可替换成两个独立标量法向弹簧。共同加载方向 `(1,1)` 的
特征值为 0，是完美塑性的真实平台；差分方向 `(1,-1)` 的特征值为 E。
这不说明受两壁位移约束的整体平衡必然奇异：活动约束消除了共同压缩机制。
应检查实际求解的受限自由子块，不先求完整塑性 K 的逆，也不靠 pinv、加硬化
或添刚度过关。有限增量径向返回/屈服角点的数值中心差分不必逐项等于上述
连续加载切线；上述式子的作用是独立说明耦合与零模态的物理来源。

## 6. 独立 2DOF 互补性例子：不得调用被测函数生成期望

使用纯制造线性系统 `K=[[2,-1],[-1,2]] N/m`，`Fint=-K*u`；上界刚壁
`u_i<=d_i`，接触力 `-lambda_i`。K 的特征值为 1、3 N/m，正定。
定义平衡 `-K*u-lambda=0`，`g=d-u>=0`，`lambda>=0`，`lambda*g=0`。

| 壁位移 d（m） | 独立平衡 u（m） | lambda（N） | gap（m） | 活动集合 |
| --- | --- | --- | --- | --- |
| `(-1,-1)` | `(-1,-1)` | `(1,1)` | `(0,0)` | 两壁 |
| `(-.5,-1)` | `(-.5,-1)` | `(0,1.5)` | `(0,0)` | X 临界、Y 承载 |
| `(0,-1)` | `(-.5,-1)` | `(0,1.5)` | `(.5,0)` | 仅 Y |
| `(-1,.5)` | `(-1,-.5)` | `(1.5,0)` | `(0,1)` | 仅 X |
| `(0,0)` | `(0,0)` | `(0,0)` | `(0,0)` | 零力退化 |

例如 X 开放而 Y 活动时，自由平衡 `2*u_x-u_y=0`，故 `u_x=u_y/2`；
凝聚刚度 `Kyy-Kyx*Kxx^{-1}*Kxy=2-1/2=1.5 N/m`，不是孤立的 2 N/m。
固定 `d_y=-1` 并回程 X，真正释放阈值是 `d_x=-.5`，不是 0。
若错误保留两壁到 `(0,-1)`，得到 `lambda=(-1,2)`，不能将负项裁零而保留
错误 u。必须解除 X 约束、重解整体平衡，得到表中解。
这些是算法交叉耦合基准，不是对实际三维 SPH 全刚度矩阵的替换。

另一个独立审查者补充共享自由分量 z 的 3DOF 例子：
`K=[[2,0,-1],[0,2,-1],[-1,-1,3]] N/m`。只有 x/y 两个壁接触，z 始终自由。
其自由平衡给 `3*z=x+y`，不是每个壁各自带一套独立 z。
两壁 `d=(-1,-1) m` 时，`u=(-1,-1,-2/3) m`、`lambda=(4/3,4/3) N`。
改为 `d=(-1,0) m` 若仍双活动，先得到 `lambda=(5/3,-1/3) N`，故 Y 必须释放；
释放后再加 `2*y=z`，解得 `u=(-1,-1/5,-2/5) m`、`lambda=(8/5,0) N`，
`gap=(0,1/5) m`。这些分数由以上线性式独立求解，用于检验活动集合和共享自由
分量的重平衡，不调用被测函数制造参考答案。

## 7. 功账与给定采样节点的独立积分参考

逐壁分别记 `Delta Wwall_f=-sum(lambda_mid_f)*Delta d_f`；逐接触材料功
由同一接触力与实际材料点位移相乘，再求和。不可以把两个 wall displacement
平均后乘总法向力，也不能在释放后仍用有载起点反力乘整段壁位移。
共享边粒子的功是两个方向贡献之和，不得重复计入整个向量功。
roller 不动则支承功为零。法向接触功、塑性功、返回算法诊断及能量缺口独立保存；
本问题无摩擦/热，任何账差都不能转成热。

两个程序加载相同，独立加载应力为 `-min(E*a_node,Y)`。
对每相 8/16 个均匀请求节点做端点梯形积分，且卸载零力释放有真实分段节点时：

| 每相请求增量 | 总加载梯形功 J | 总净梯形功 J | 净功减连续 P（J） |
| --- | ---: | ---: | ---: |
| 8 | `.600000000000000000` | `.484285714285714286` | `-.004285714285714286` |
| 16 | `.603750000000000000` | `.488035714285714286` | `-.000535714285714286` |

两者卸载均为线性弹性段，释放分段后卸载总功精确为 `-.115714285714285714 J`；
交错程序 `.15 s` 的拐点也必须纳入。这些是独立均匀连续体按指定节点采样的答案，
不是对所有空间离散 SPH 解强行施加的容限，更不是实验数据。
跨屈服端点积分差与跨脱离漏分段是不同机制：前者需报告，不补热；后者会破坏
壁/材料功共轭，必须通过活动路径处理，不能用事后能量修正掩盖。
