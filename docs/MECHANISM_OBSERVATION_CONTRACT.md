# 工程过程观测算子（只读，2026-10-01）

本轮将“实际塑性/送料/铺展”和“能运行/能出图”分开；观测绝不回写求解器。
以下定义先于观测程序执行冻结，原始值保留，不按期待趋势调阈值。

- 使用accepted VTK/checkpoint，不把REJECTED并入。跨段读取先验证父子衔接。
- 自由材料：actuator==0；棒料：component_id==1；基板component_id==0。
  tracer/wholebar/AS/RS标签不用于以下力学机制判定。
- 塑性同时报告ep>0原始计数与ep>1e-10计数；后者只是观测噪声门槛，
  无量纲、工程观测假设，不是物理屈服阈值；不裁原始ep或塑性功。
- 塑性功从checkpoint的plastic_work逐粒子(J)统计，
  不是把能量残差或摩擦热当作塑性功。报告负值计数而不裁剪。
- 规定轴向进给量=feed*t。实际穿过z=layer的质量采用持久feed_crossed；
  同时记录“原z0>=layer、当前z<layer”的净位置指标，二者不混淆。
- 孔外层内棒料候选区：0<z<=layer，工具平移/转动坐标中
  max(|x_local|,|y_local|)>bore_width/2，且为自由棒料。
  候选体积=sum(m/rho)，是粒子中心区域分类的三维材料体积代理，
  不是截面面积、Fig8实验比例，也不直接证明接合/持续沉积。
- 实验室x/y/z保存不变；局部旋转只用于几何查询，不是给自由粒子施加速度。
- “持续沉积”“三工况趋势”“论文定量”不能由上述任一单一非零值授予。
  原有限棒、预结合接口、2um初始过盈必须在解释中保留。
