## 已确认的接触实现缺陷：切向投影

活动函数 `interactions_calculate_force_die_using_penalty_method`：

- 圆孔侧接触：`src/interactions_gpu.cu:918–938`，第 933 行为 `vr = v - v * normal`。
- 出口扩孔段第 963 行、下模平面第 982 行、容器底面第 1001 行、容器侧面第 1022 行重复该形式。
- 默认 `src/types.h:49,74` 定义 `USE_DOUBLE` 和 `vec3_t=glm::dvec3`。
- 随仓库 GLM 的 `glm/detail/type_vec3.inl:705–711` 明确将向量 `*` 实现为逐分量乘法。因此这里不是点积。

独立手算（没有运行上游）：

```text
n = v = (1/sqrt(2), 1/sqrt(2), 0)
正确切向速度：v - dot(v,n)*n = (0,0,0)
当前代码结果：v - v*n
            = (1/sqrt(2)-1/2, 1/sqrt(2)-1/2, 0)
            ≈ (0.20710678, 0.20710678, 0)
该结果沿法向分量 dot(result,n)
            = 1-1/sqrt(2) ≈ 0.29289322 ≠ 0
```

这是可由类型定义和代数证明的实现缺陷，不是合法的“工程近似参数”。尤其圆孔/曲面法向并非总与坐标轴重合。修正该式也不等于其余接触和能量账已经正确。

## 本构与热耦合

1. **本构温度输入截断已确认，存储温度并非在此直接裁剪。** `src/actions_gpu.cu:569,584–587` 先取局部 T，当 T>Tm 且 clamp_temp=1 时，将代入本构的 T 改为 Tm−1；默认材料 `src/materials.h:384` 打开这一开关。`particles.T` 在第 669 行继续累加塑性温升。这一区别不改变不宜原样采用的结论，但不能误报成“所有输出温度都被封顶”。

2. **低率 JC 是另一套显式近似。** `src/plasticity.cuh:72–91` 对归一化率 >1 用对数式，<=1 用 `(1+eps_dot)^C`。没有在该函数发现硬性应变率下限。返回映射中负塑性乘子用 fmax 截为非负（`:99–100`），迭代负猜测被反向乘 0.1（`:131–134`）。这些与本项目 FKS 低率模型不能混称为同一材料。

3. **速率缩放一致性尚未证实。** 返回映射 `src/plasticity.cuh:100–102` 在内部直接用增量/dt；存储的新应变率在 `src/actions_gpu.cu:627` 再除 Vsf，并用于塑性热处的屈服力 `:662`。需按作者预期重新推导内外率参数一致性，不能只关闭 ms/Vsf 就宣称完成无缩放版本。

4. **局部求根失败并未拒绝整个时间步。** `src/plasticity.cuh:141–144` 标记 failed 后返回当前迭代值；`src/actions_gpu.cu:620–646` 只打印信息，仍更新塑性量与应力。未观察到本项目“候选拒绝且保留旧接受状态”的事务协议。

5. **导热真正接到了活动路径。** `src/types.h:122` 打开 PSE；`src/leap_frog.cu:213–215` 每步调用；`src/interactions_gpu.cu:121–205` 含邻域温差、调和导热率及工具/材料参与。它不是仅 README 声称有热学。该项的守恒与稳定性没有在本次审计中数值验证。

6. **工具热物性被同一公式覆盖。** `src/actions_gpu.cu:60–74` 读取 part 却未按其筛选；所有未 blank 且 T<=Tm 的点都更新为同一 cp(T)、k(T) 公式。初始钢工具与容器不同 cp/k（benchmark `:279–280,314–315`）随后也被该函数改变。若目标是钢/铝保留独立热物性，这是实现不一致；不应当作经过验证的钢铝接触热模型。

7. **塑性热与摩擦热输出不是完整能量账。** `src/actions_gpu.cu:654–669` 实际向 pl_heat_gen 累计的是逐粒子温升；`src/interactions_gpu.cu:808–810` 虽计算 heat_gen 能量局部变量，累计的 fr_heat_gen 仍是温升 T。CSV 名称不能代替单位核查。`src/vtk_writer.cpp:39–58` 的动能/内部功比由 `vel.w` 的应力功累加（`src/actions_gpu.cu:290–292`）构成，并不是外功、弹性储能、塑性热、摩擦热、导热、人工项及删除粒子通量的闭合证明。

8. **边界对流是明确数值选择。** `src/actions_gpu.cu:679–716` 对 fixed=7/9 使用不同系数，并在 T<Tref 时设 h_conv=0。热参数亦乘 Vsf；不能当作通用自然对流定律原样迁入。
