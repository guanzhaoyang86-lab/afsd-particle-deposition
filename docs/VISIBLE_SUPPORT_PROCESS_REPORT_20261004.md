# 开源方法适配与统一可见邻域：过程短窗结果

本轮已经修改代码并实际运行。新空间变体从已接受的39.375ms父态出发，通过
8个同终时粗细比较，正式接受16个62.5us细步，终时达到40.375ms、累计447步。
新变体越过原未过滤模型在39.875ms遇到的工具实体遮挡；旧模型的失败记录保留。
当前仍没有证明持续肩外塑性铺展或沉积完成，也没有论文定量验证。

## 从哪些开源实现借鉴

针对当前的“相互作用边穿工具”卡点，核对实际源码及调用链，而非只看功能简介：

- [Peridigm固定源码](https://github.com/peridigm/peridigm/blob/f25c4928e850b2aa0012bc5d3b8b1ec5c78c8903/src/io/pdneigh/NeighborhoodList.cxx#L703)：半径搜索后应用几何过滤，只将未排除的邻居装入最终图。
- [MOOSE固定源码](https://github.com/idaholab/moose/blob/e6a7269a5c8e884ea82a7b64ac687043d219022c/modules/peridynamics/src/mesh/PeridynamicsMesh.C#L246)：排除跨裂纹键时同步建立双向邻域和支撑统计。
- SPHinXsys本轮所读Inner/SelfContact路径没有直接给出本项目旋转工具的遮挡处理。
  PySPH继续提供原有3D NNPS；不需要为这项改动更换后端。

本轮借鉴构图顺序和同步重建原则，未将外部裂纹几何或材料模型直接复制为AFSD求解器。
11个源码/许可证原件、固定提交与SHA收据见
`outputs/open_source_visible_graph_review_20261004/source_review_receipt.json`；完整核对见
[开源源码报告](OPEN_SOURCE_VISIBLE_GRAPH_REVIEW_20261004.md)。这些仓库未替本项目完成
移动工具、热塑性、接触与图切换的联合验证。

## 实际修改

新分类为`HOT_QS_VISIBLE_SUPPORT_CHAIN_RULE_CONTACT_APPROXIMATE_V1`，属于ENGINEERING_APPROXIMATE。
唯一后端仍为PySPH `1cd3dea9cfaac7d9f1bda2a2491ce4b42a31dbe5`。

| 新文件 | 行为 |
|---|---|
| `scripts/visible_support.py` | 对真实NNPS候选边作有限工具实体可见性过滤，保留raw/kept/blocked索引、PID、区间及指纹；标签不参与 |
| `scripts/visible_support_numerics.py` | 在过滤前检查数值适用域及圆柱判别式不确定性，未决时拒绝整个候选 |
| `scripts/visible_quasistatic.py` | 在密度固定点之前接入统一图，重建修正梯度/材料率/配对力/导热/切线；显式转接原历史 |
| `scripts/visibility_equilibrium.py` | 完整力余项控制的Broyden；接受搜索点图变更时舍弃跨图更新并要求刷新；失败也保存实际图 |
| `scripts/visible_support_path.py` | 对保留图的整个声明步内路径作有界保守检查，FOUND/UNRESOLVED均拒绝 |
| `scripts/run_visible_support_process.py` | 同真父cost→8 coarse→16 fine；来源、预算、fresh求值、能量、路径及逐对局部比较共同控制发布 |

旧冻结物理源、旧接受链和旧FAIL均不修改。工具几何、接触、本构、材料热源及原始
功热公式沿用。未使用质量/时间/模量缩放、GPU、裁温度、裁屈服或负耗散隐藏。
转接只另立空间模型分类与来源，不清零速度、应力、温度、塑性、接触历史、被动观察
或431条历史能量记录。原动态分支1.3503936us与此独立450°C热态慢过程不相加。

过滤不是删掉输出里的坏边。密度/修正矩阵、内力、热扩散及搜索切线实际使用同一
过滤图，随后重新求平衡。旧39.875ms失败路径上仅替换图，力差最大0.340843N，
scaled force由0.292265变为33353.674，因此该旧候选不能直接接受。新过程从真父
重新计算，不从旧失败参考重启。

## 当前范围

可见图修复了已定位的空间耦合问题，使新变体在这个1ms短窗内越过旧失败位置。
它尚未建立完整AFSD工程模拟器：制造二次场的细网格梯度RMS仍约为解析参考尺度的
45.2%，不能宣称空间收敛合格；FKS低率量纲、Jaumann循环功、边界牵引、有限接触面
重叠、启动与热接触参数等限制仍在。28/3/15组件结果不是全量回归，更不是实验验证。
旧1246项全量记录中的10FAIL/1ERROR/3expected failures未重跑，也未改为绿色。

端点图用于整个BE增量，删除边早期的作用没有另外积分；同父局部时间比较提供的是
这个离散模型的短窗数值证据。起点被遮挡而终点释放的保留边会被路径审计拒绝，
因此不能声称解决了所有动态可见性事件。路径判据是限定数值域的浮点工程证书，
并非形式化区间算术证明，也不是未知真实连续材料轨迹的证明。

下一项过程证据应是同一新模型内进一步的出口后塑性铺展及空间/时间敏感性，
而不是以过滤边数、组件数量或已有两次中心穿越代替沉积完成。
