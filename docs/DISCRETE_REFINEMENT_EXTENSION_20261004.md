# v3 启动时间分辨率诊断补充合同（运行前）

仅当v3的两个半步都通过原始累计能量/力/几何门槛、但同终时误差未通过时，允许
从同一独立初态进行4×0.125ms，与2×0.25ms比较；若仍未通过且成本门槛允许，
最多再进行8×0.0625ms，与4×0.125ms比较。不得更改10%应力/20%ep/5um位置/
0.5K温度门槛，也不得继承一个未通过累计能量的中间状态。

每个任务启动前以最近完整分辨率任务的平均根成本，乘根数、1.5安全因子并加30s，
超过450s则NOT_RUN。全任务540s内停/600s外停。每根仍24更新/100残差。
任何首个不合格前缀立即停止，并记录已通过前缀；不会“先跑完再看累计账”。

这只是辨别启动接触与率相关应力的时间误差趋势。未通过不能启动长段生产；通过
也必须按实际物理步长和每步成本估算0.13s目标，不能用组件速度冒充过程速度。
若所需成本不满足限制或时间误差不随细分下降，停止相同方案的步长堆叠并报告。
