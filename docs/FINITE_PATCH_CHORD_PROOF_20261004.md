# 有限接触patch的弦段下界：独立推导与实现边界

本文是只读方法审查，不是新的物理积分器或已执行的过程验收。旧接触源、查询预算、
失败记录与接受门槛均不修改。下述下界是充分条件：证明失败只能记UNRESOLVED，
不能据此判定已接触；只有实际几何距离发现小于粒子半径才可记FOUND。

## 1. 从真实声明曲线到整条弦

使用旧实体扫掠已经声明的世界坐标线性粒子/工具平移、最短SO(3)工具旋转路径。
全局步内参数为s∈[0,1]，令

    r(s) = x0 - o0 + s [(x1-x0) - (o1-o0)] = r0 + s Δr
    q(s) = r(s) R(s)

其中q为工具局部坐标。不能把局部坐标端点之间的直线当作真实q路径；它只用作有界近似。
若整步旋转角为θ，正交旋转的导数给出

    ||q''(s)|| <= 2 θ ||Δr|| + θ² max(||r0||, ||r1||) = M.

理由是q''=2Δr R'+r R''，旋转导数范数分别不超过θ及θ²，且仿射r(s)的范数
不超过端点范数的较大者。这是对整步fraction s求导，不能在子区间内重复或遗漏h缩放。

对任意子区间[u,v]，h=v-u，L(s)为q(u)、q(v)之间同参数的弦。二阶导数的
线性插值余项（等价于端点零值二阶微分方程的Green核积分）给出向量界

    ||q(s)-L(s)|| <= M (s-u)(v-s)/2 <= M h²/8 = δ.

向量界不需要额外√3：对任意单位投影应用同一个标量余项界，再对投影取上确界即可。
实现必须继续加上坐标算术、旋转非正交以及Rodrigues终点与输入R1的别名误差余量。
该余量不能仅按曲率项大小定标；应包含世界坐标、工具几何及局部坐标尺度。

设固定局部patch为F，上包含集合S满足F⊆S。距离函数为1-Lipschitz，因此

    dist(q(s),F) >= dist(q(s),S)
                 >= dist(L(s),S) - δ
                 >= min_{t∈[0,1]} dist(q(u)+t[q(v)-q(u)],S) - δ.

若下界再减独立向下舍入余量后，严格大于粒子半径r_p，整个子区间对该patch
没有罚壳活动。这里只使用明确声明的插值路径，不证明真实未知的步内物理轨迹。

## 2. 通用闭box与弦段的最小距离

用一个通用routine处理S=Π_k[l_k,u_k]，允许无限端点及l_k=u_k的退化轴。
弦p(t)=a+t b，t∈[0,1]，点到box距离平方为

    D(t) = Σ_k [p_k(t)-clip(p_k(t),l_k,u_k)]².

求最小值可在实数算术中精确归结为有限候选集：

1. 加入0、1，以及所有满足0<t<1的有限坐标bounds交点t=(bound-a_k)/b_k。
   b_k=0时该轴没有交点；无限bounds不参与除法。
2. 排序、去重这些断点。每个开子区间内，每一轴的clamp分支固定。
3. 此时D是凸二次式；将每段端点及落在该段内的驻点加入候选集。
   若二次项为0，该段恒定，端点足够；不能用随意数值阈值丢掉一个非零斜率。
4. 最后对全部候选重新直接计算p(t)与box的clamp距离并取最小，避免用展开
   多项式在接近零距离处做大数相消。结果仍须向下误差包裹，才可成为证书。

BORE_X±可直接表示为 x=±a、y∈[-a,a]、z∈[0,H] 的闭box；BORE_Y±同理。
这是有限矩形本身，既保留壁法向距离，也保留孔口棱边的另外两个距离分量。
相比无限壁平面，其下界不会因为点在矩形延长平面附近、却在矩形边外而永久失效。

必须处理零长度弦、平行轴、退化矩形、交点重复、交点恰好0/1、无限bounds、
同一位置处多个clamp切换，以及很短子区间中“中点舍入成端点”的情况。
区间分支不确定时应增大可论证的误差包裹或返回UNRESOLVED，不能猜一个分支接受。

为避免小方向或大参数比值溢出，可先根据有限端点坐标判断某bound是否会在段内被
跨过；分段驻点也宜采用局部区间参数、缩放后的点积。禁止生成0×∞或∞−∞。
double结果不是形式区间算术证明；需明确其保守浮点误差假设，所有最终证明使用严格>。

## 3. SHOULDER/TOP的通用上包含集合

高度z=c的实际盖面可写为闭圆盘去掉开方孔：

    F_c = {z=c, x²+y²<=R², max(|x|,|y|)>=a}.

第一个上包含集合A_c为四个外侧半平面之并集：

    {z=c,x>=a} ∪ {z=c,x<=-a} ∪ {z=c,y>=a} ∪ {z=c,y<=-a}.

每个成员都是允许无限端点的退化box，可复用同一弦段到box routine。
对四个最小距离取min，才是到并集的最小距离；取max会产生错误的过高下界。
这会保留方孔边缘的横向间隙，解决仅用无限z平面时即使无限细分也无法证明的问题。

第二个上包含集合D_c是整个闭圆盘。可以另外求其保守弦段距离下界L_disk，
再使用max(L_union,L_disk)作为到F_c的下界，因为F_c是两集合的交。
不能把两个独立距离直接相加，也不能把max声称为到交集的精确距离。

一个便宜但可能较松的圆盘下界是：

    z_min = min_{t∈[0,1]} |p_z(t)-c|
    ρ_min = min_{t∈[0,1]} ||p_xy(t)||
    L_disk = sqrt(z_min² + max(ρ_min-R,0)²).

这两个最小值不需要在同一个t取得，仍然是下界：任意t的两项都分别不小于各自最小值。
ρ_min必须包含xy线段内部的驻点t*=clip(-a_xy·b_xy/||b_xy||²,0,1)。
仅取两端半径的较小者不安全：圆外两个端点之间的弦可以穿过圆心。
z_min也必须考虑平面在段内被穿过的情况，此时为0。

可先取max(L_union,L_disk)，再减共同δ与总算术余量；若各下界采用不同误差包裹，
则先各自下调再取max。OUTER_CYLINDER不因此变成闭box或圆盘；未证明的该类剩余
仍须保留UNRESOLVED。BASE可继续复用原全局仿射距离界。

## 4. 必须保留的拒绝与审计范围

新方法只能补充旧审计因查询/深度预算耗尽留下的区间，不能改写原FOUND、实体失败
或来源不符结果。原始报告须保留，新的box/弦证书和算术余量另记。所有剩余区间均
证明才能升级为CERTIFIED；只证明当前最紧粒子不够。

数学下界为负或小于半径只能说明证明不足，不是隐藏接触证据。实际查询找到隐藏
活动仍必须拒绝；接触力、最近点并列、摩擦热、吸引法向、负耗散与原实体连续扫掠
一律由原物理map检查，不通过本证书修改。两端已有活动的接触不在该无隐藏壳证书
范围内，仍需原全局及局部时间筛选。

建议的独立验证应覆盖线段穿box内部、最小值在端点/面/棱/角/内部驻点、零方向、
无限bounds、退化box、ULP切换、跨圆弦、旋转曲线内部逼近与明确隐藏接触反例。
稠密采样只能找反例，不能单独证明保守性；最终应逐项检验下界构造的包含与误差条件。

## 5. 当前step019所说明的范围

已存step019的旧补证在SHOULDER的无限平面下界上反复细分，达到深度32仍未证明。
这种情况在点的垂向距离小于粒子半径、但靠方孔棱边的横向距离让实际有限patch
间隙仍大于半径时完全可能发生；继续提高同一种平面证明的预算不会改善其极限。
采用通用闭box/弦距离是在保守几何下界中纳入已有有限边界，并不改变接触模型。

真实step019是否存在隐藏活动，仍以独立诊断和之后登记的新证书为准。本文不把
“采样未发现”改称证明，不把几何补证改称时间精度通过，更不发布任何物理候选。
