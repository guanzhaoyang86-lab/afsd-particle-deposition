## 实际改动与适用范围

唯一活动后端仍为固定PySPH `1cd3dea9cfaac7d9f1bda2a2491ce4b42a31dbe5`。
本轮没有迁移后端、运行GPU、做质量/时间/模量缩放或启动三工况。

- `discrete_contact.py`新增实际参与平衡的法向离散梯度力；v3进一步采用几何距离的
  链式构造，避免直接对总势做离散梯度时在平壁引入切向“法向力”。摩擦法向及上限
  随实际新法向力计算，真实摩擦热、切向簧数值损失、释放能分开。不是仅改能量日志。
- `interval_acceptance.py`为整段累计原始能量只分配一次绝对容差，并约束逐步缺口
  绝对值之和，禁止反复利用绝对额度或步间抵消。严格孔口观察器按持久ID、真实跨越
  时间及当时旋转方孔判定；初始肩下点和绕外圆穿肩面不计为孔口通过。
- `discrete_process.py`接入新接触和累计门槛，接受前重新计算完整候选。继承原材料、
  修正三维邻域、密度、隐式热及实际约束；不重设历史，不用残差补热。
- 监督驱动保留失败、源/参数/父checkpoint哈希、完整候选、VTK、工具位姿、原始账及
  可读回checkpoint。每次540s内部/600s外部硬停，运行前估成本，拒绝覆盖旧证据。

模型分类为 `HOT_QUASISTATIC_CHAIN_RULE_NORMAL_CONTACT_APPROXIMATE`。
342粒子、450°C独立无应力初态、2.504mm孔宽/2.5mm方棒（每侧2um间隙）、底层三轴
夹持、棒顶仅z送料、预粘结棒/基板邻域和省略惯性均为明确假设。有限开放工具与底座
刚性，棒和其他基板自由度可变形。原FKS参数及1/s低率地板保留；尚无材料标定。
旧总位移50um守卫未被直接删除来续算旧模型；本独立有限几何模型每步位移<=50um，
并对真实刚体运动和粒子路径做实体扫掠。总净位移可超过50um，但不能据此称已穿孔。
