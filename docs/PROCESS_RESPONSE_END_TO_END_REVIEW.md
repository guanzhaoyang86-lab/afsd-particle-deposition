## 结论：当前接触导数工作有价值，但离可负担输运还有独立缺口

目标沿用 AGENTS、ENGINEERING_APPROX_CONTRACT、PROCESS_COMPLETION_CONTRACT：
同一固定 PySPH 后端上的、物理驱动且可审查的 ENGINEERING_APPROXIMATE 三维
AFSD 过程，不是逐式论文认证，也不是27粒子测试平台自身的完工。

**完整接触路径响应修复即使通过，也只能解除一个数值求根候选缺项。**
它不会自动赋予当前 HHT 分支正塑性、受约束多面粘滑、旋转法向、孔口进出、
可持续供料或可负担工艺步长。更不能把当前6us局部基准接到850ns真实状态上。
应将本轮限定为“一次有独立参考的接触响应验证，以及有条件的一次冻结失败
候选诊断”；随后给出实际AFSD接口/准确性/成本的联合判断，不能无限重复近停滑小修。

当前没有足够依据给完成百分比、剩余开发天数或论文尺度墙钟承诺。证据支持的是
“基础设施和若干方法组件可复用，但核心过程输运未建立”。生产仍不允许。

## 2. 实际入口和调用关系

```text
旧显式调试入口 run_afsd_debug.py → application.run → SolidSolver/HostLeapfrog

真实耦合入口 run_coupled_afsd.py → IntegratedSolver
   geometry/contact_rows + axial_actuator
   → current NNPS/corrected gradient → SAME-history Jaumann/J2/FKS
   → paired internal force → coupled_boundary/event-aware constrained kick
   → coupled_thermal → diagnostics/accepted checkpoint

真实连续分支 run_nonlinear_continuation.py
   → UpdatedTrial五场映射 + stage_anderson
   → 原接受条件 → continuation_state原子提交/实际重载 → transport_observer

制造块 probe_hht_stop.py
   → hht_stop_stage.advance_private → hht_stop_contact路径积分/BE热/联合根
   → certify_interval / locate_duration / restart_sliding → 独立基准输出
```

在当前 `solver.py`、`coupled_solver.py`、`updated_trial.py`、
`run_nonlinear_continuation.py` 和 `run_process_global.py` 中，没有把新增HHT、
finite_tool_geometry、inlet_protocol直接接入真实AFSD的调用链。
存在文件/类不等于该物理已进入真实接受轨迹。

### 有限工具不是一个可无痛替换的几何函数

`FINITE_OPEN_SQUARE_DISTANCE_APPROXIMATE`的单实体距离罚势和现逐face叠加
罚势是不同接触模型。`PROCESS_GEOMETRY_INDEPENDENT_REVIEW`已有同一点两者
力/势不同及孔内中轴不光滑的独立反例。新组件遇活跃多最近点拒绝；旧模型
`IntegratedSolver._feature_transition_guard`拒绝非零储能feature消失。
因此下一边界集成必须显式选定一个有依据的接触表示，并验证经过孔口/肩缘时的
法向势能、切向功及刚体功；不能接上新distance后删除guard或暗自圆角/封孔。

## 4. 当前真实几何在其有效域内不可能产生穿越

`configs/benchmarks/coupled_afsd.json`是342点有限棒/基板问题：dx=.5mm，
层高1.5mm=3dx，轴向进给2.12mm/s，maximum_displacement_m=50um。
`UpdatedTrial._check_state`检查到原始位置的总位移，非每步位移。
经已保存几何读回，任一棒中心距肩面最近250um：50um界内仍至少差200um。

这不是当前时间步太少的统计现象，而是域约束使中心穿越在数学上不可能。
不能靠更多50ns试跑或放大dt解决，也不能直接取消保护。先补所经过有限feature
和事件功，再预先声明扩大的适用域。其他密度/穿透/温域/NaN/质量保护保持。

首个真实输运里程碑可以使用**既有有限棒库存**，暂不插粒：固定身份集合、真实
执行器、材料通过开放孔口/肩面、随后持续一段自由塑性铺展。这样可先复用当前
observer/质量账，避免把持续入口开发当作第一次穿越的无谓前置条件。
这是建议的有限库存阶段，不是持续供料完成，也不能缩短初始gap或预置肩下点来
伪造穿越。中心穿越本身仍不是沉积体积、论文截面积比或冶金结合。

## 5. 成本判断：只能用实测，不能用27点速度乘粒子数猜测

实际342点四阶段平均59.1181176s/50ns，物理/墙钟比约8.46e-10。
nominal执行器推进250um需0.1179245283s；这是命令尺度，不是自由材料实际穿越
时间的预测。若保持旧步长/成本，约2358491步、1613.77天；这只是反证直接堆步
不可行的粗外推，不是开发期限、真实生产预测或新的运行计划。

在600s内覆盖该名义时间尺度，忽略额外事件/输出开销的必要平均预算如下：

| 假设过程步长 | 名义步数 | 300rpm每步转角 | 可用平均墙钟/步 |
|---|---:|---:|---:|
| .1ms | 1180 | .18度 | .5085s |
| 1ms | 118 | 1.8度 | 5.0847s |
| 10ms | 12 | 18度 | 50s |

这些不是已可接受步长。现HHT制造块最大已接受步仅1us，其固定法向范围也不能
代表1.8度旋转过程。`PROCESS_CURVED_CAUSAL_REVIEW`的769–1742s/1ms只适用于
27点旧scout粗外推，已超600s；不能向真实342点/论文尺寸套用。

实际热显式界约0.292ms，比50ns大5843倍，故隐式热虽有价值，不是当前微步瓶颈
的单独解药。342点冻结结构D/K装配.1594s、整体只读响应1.8176s也不是完整根的
单步时间。实际500ns联合根曾耗265s仍失败，说明“隐式稳定”与“准确且便宜”不同。

下一成本证据必须来自拟集成的真实参数/构形/约束/材料/边界接口：包含残差评估、
线搜索、事件细分、输出和失败开销；再记录同终时差异。当前无此新接口的实测成本。
即便加速器存在也不能据此填预算；本任务不做GPU、并行或其他性能工程。

## 6. 有限关键路径与停止条件

不是按以下编号宣称百分比，也不是要求把每格无限细拆。

**当前包的终点：完整接触响应的独立验证/因果判断。**
用独立公式/有限差分核对实际DeltaJ项、法向gap、PRIVATE符号和整路径，而不是
只验端点力。若允许，再对同一saved trial5最多一次私有、原预算/原容限诊断。
通过说明有一个缺失导数得到修复；失败则保留并结束该假设的修补，不再盲跑scout。
均不新增真实AFSD时间，不能把它当作最终端到端交付。

**下一实质工程交付：一个真实AFSD适配候选与可行性判据，而非另一个墙频率基准。**
把上述可复用设施收束到同一具名过程接口：同史正塑性/BE热、实际受约束轴向反力、
多面粘滑，以及随工具位姿的有限接触。先冻结明确的有限库存范围、接触表示、功热
定义、时间误差和运行预算；不重搭项目、不替换默认旧路径。
第一交付应包括在真实342点接受状态上的**非提交接口检查/成本探针**，以及少量
独立的联合正塑性-摩擦-热/旋转多面-约束基准，不能只移除现有拒绝条件。
局部根误差门和工程可观测量时间误差门分开；后者事前确定，不为了绿而改旧FAIL。

到此必须能作出一个明确选择：

- 在保持惯性/真实参数的范围内，存在事前限定的时间步策略使同终时过程量误差、
  接触/热/质量安全和完整成本相交：才登记一次<=600s有限库存输运探针。
- 经有限预注册策略仍找不到交集：报告该路线在当前范围**不可行/未证明可行**，
  停止投资同规模微步；提出有取舍的模型范围决定，而不是继续累加组件PASS。

**随后可验收的物理交付：有限库存短段输运。**
必须有最初肩上自由材料ID的实际向下穿越、接触驱动塑性铺展、棒/板三维响应、
工具位姿/热账/反力功和失败分离；与同物理域/共同终时的可负担细化及独立重启
比较绑定。若只到达时间却cross=0，报告“无输运”而不是动画重构完成。
若预算不足，保留NOT_RUN，不拆多次600s规避长期授权。

**最后才扩展持续供料、较长道次及多工况。**
真实入口的接受事务/源账/观察算子不可省略，但可在有限库存输运已经成立后接入。
再做实际可支付成本与敏感性、源材料/边界假设和定性论文图像比较；生产三工况
和长时任务仍需明确授权。Fig.8实验面积比不能由3D点数比代替，缺原始数据则
定量验证继续BLOCKED，不影响诚实交付较窄的工程近似过程。

## 7. 哪些是方法开发，哪些必须重新作范围决定

- 独立接触导数、原子提交、相同物理下时间积分/事件算法及已明确近似模型的小范围
  联合验证，可继续在现工程目标内开发；不需要每个函数重新请求用户选择。
- 单实体罚势替代逐face罚势、温变材料数据假设或本构变体，需要明确命名、来源、
  独立基准和适用域，不能声称只是bugfix。当前正塑性接入不要求立即重写本构；
  旧自由能/空间FAIL可作为已批准APPROXIMATE风险继续记录，但不能伪造热力学闭合。
- 若保惯性路线无准确性/成本交集，可提出文档已有的热态慢过程准静态备选；
  **不能静默删除当前预压释放的惯性、清零850ns速度或拼接旧checkpoint**。
  需要用户接受“启动/预热不模拟、另解平衡初态”的新物理范围，再独立验证。
- 600s以上/付费/生产运行需要新的明确授权；GPU/并行、质量/时间/模量缩放、
  自由材料轨迹驱动、标签改变受力及裁温/裁负耗散均不在当前授权内。
