# 有限外部沉积阶段监督

`supervise_afsd_deposition_20261007.py`仅使用Python标准库，不导入物理runner、
模型、PySPH或NumPy，不修改任何冻结实现。它以新的隐藏子进程调用既有remote
runner；每个子进程仍执行全部原始源/身份/历史/物理/几何/能量/粗细比较门槛。
现有diagnostic-only授权范围不变，不创建消息、自动化、正式接受或假沉积结果。

从明确指定的cost和最新PASS父阶段开始，默认最多12段、总墙钟3600s、全局诊断
目标0.22s，首次通过比较观察到新料肩下质量即停止。默认max-dt5ms、min-dt3.90625us、
max-halvings8；当前dt由父阶段建议继承。每段候选额度为
floor((450−30)/(1.5×max(cost预测候选秒数,父段实测最长候选秒数)))，最多18；
不足3时停止并要求重新评估成本。max-macrosteps=min(6,额度//3)。

子runner内部540s、外部600s；本监督再施加650s上限，超时只终止本监督创建的
子进程树，保存所有文件。下一段启动前要求总墙钟预算还剩650s，因而可能提前
停止以保留硬上限，不把预计时长当成执行保证。首FAIL、超时、时间/步数不增加、
哈希不匹配或目录冲突均停止，不自动跳过失败或沿失败候选继续。

监督核验cost/父子manifest与supervision、源和artifact哈希、精确fine候选与PASS
比较绑定、共同独立起点和直接父态。只有完整核验PASS才能提升progress中的物理
时间、步数、最后screened checkpoint和新料质量；运行中的子段观察另列字段。
每PASS原子写progress.json，包含当前阶段、下一阶段、墙钟及继续所需路径。
监督自身源与契约、成本/起始父收据也记录SHA256，结束再次核验。

`--preflight-only`只读验证和计算下一预算，不启动solver、不建立输出目录。
screened物理时间始终是工程近似诊断时序，正式接受时间恒0；肩下新料不自动代表
稳定后方沉积或冶金结合。实际全局目标未达到时只报告真实已完成的时长。
