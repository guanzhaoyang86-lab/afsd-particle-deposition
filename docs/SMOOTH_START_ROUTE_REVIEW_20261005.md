# 20 ms 平滑启动路线的只读评估

结论：可作为**独立工程启动敏感性试验**，有理由研究能否减轻最初的接触与材料分支变化；目前不能把它当成已解决时间推进或能完成沉积的路线。若只得到启动初段空载大步通过，证据仍不足。本文没有实现模型、修改冻结文件、运行物理或新增接受时间。

## 已核验的起点与失败

918 粒子独立支线目前仅接受到 68.359375 μs／20 步。随后 coarse 3.90625 μs 与两个 fine 1.953125 μs 的第一对比较失败；三粗候选及两细候选共耗时 96.818535 s，新增接受时间为零。独立读回 PASS 只表示失败与证据一致，绝非过程 PASS。

PID 893 在真父状态已处于 BORE_Y_MINUS 滑动。coarse、fine1、fine2 的有效总偏应变率分别约 1.00130、1.01499、1.09374 s⁻¹；coarse 和 fine1 有新增塑性，fine2 无新增塑性。保存字段解释给出 fine2 等效应力约 1.69011 MPa，FKS 标量屈服约 1.88996 MPa，与弹性分支一致。三个最终根均通过原力残差门槛，无 Newton 回退。不能据此唯一归因于接触、FKS 或求根器。

该粒子的应力差 10.38814%、塑性差 21.99011% 超过原 10%／20%。塑性比较采用 1e-5 下限，实际绝对差 2.19901146e-6 大于允许的 2e-6；下限增大了分母，去掉下限会使误差升至约 25.0290%，不能将本次失败解释为下限造成的虚假失败。

## 当前启动程序究竟是什么

`quasistatic_process.independent_initial_state` 从新几何独立初始化，速度、应力、塑性与接触历史初值为零，不读取旧动态状态。其 `pose` 使用 θ=ωt、x=vt；`prescribed(dt)` 对初始棒顶 z 轴施加 −feed×dt。故从第一个正时间步就施加额定旋转、走速和进给。当前自由轴平衡方程只有内力与接触力，没有惯性项；这里的微秒敏感性应称加载速率、接触与弹塑性积分的瞬变，不能解释成正在解析惯性波。

材料 `update` 的 rate 为总偏应变率范数 `sqrt(2/3 dev(D):dev(D))`，不是塑性应变率。FKS 使用 `max(rate,1 s⁻¹)`。在初温 723.15 K，率乘子为约 `1 + 2.74099 ln(max(rate,1))`；跨过 1 s⁻¹ 后，rate 增加 1%／10% 分别可使该乘子增加约 2.727%／26.124%。该下限处导数改变，并非零速过零问题。ramp 不消除这项模型假设，且可能把其敏感区推迟至以后。

初温、零塑性、rate≤1 时的屈服约 1.51729 MPa；`Y/(3G)` 约 1.92306e-5，是材料等效弹性屈服应变的量级。在 rate≈1 s⁻¹ 时对应约 19.23 μs。1–4 μs 步长已经占这一量级的约 5%–21%。这只是解释性尺度，不是稳定性定理或可接受步长证明。

## 一个明确的新 ramp 假设及其影响

可考虑所有外部速度共同使用速度因子 `r(s)=3s²−2s³`，s=t/Tr，Tr=20 ms，区间外分别为 0、1。其积分为 `R(t)=Tr(s³−s⁴/2)`；t≥Tr 时 `R=t−Tr/2`。位姿应为 θ=ωR、x=vR，棒顶位移为 −feed R，不能误用 `t*r(t)` 或仅修改工具运动而保留瞬时送料。

20 ms 时速度达到原 300 rpm／2.12 mm/s，但累计转角仅 18°，送料与走向位移各为 21.2 μm；恒速启动对应 36°、42.4 μm。因此这是不同的加载历史，绝非旧接受状态的延续或仅变换时间标尺。总应变率相关材料、热扩散与接触耗散也随之改变。初始网格尺度 dx=0.5 mm，热扩散率约 6.87243e-5 m²/s，dx²/α≈3.638 ms；20 ms 足以改变局部热历史，不能假设 ramp 前后温度相同。

初始方孔与棒外表面单边间隙约 2 μm。以未变形棒表面中心距转轴 1 mm、法向扫速约 ω×1 mm±traverse 作粗估，恒速约 59.6–68.3 μs 扫过间隙，与当前首接触量级相近。上述 ramp 的同一几何粗估约为 2.95–3.09 ms，速度仅额定的 5.9%–6.4%。这些不是受力求解所得接触时刻。

因此启动初几十或几百微秒的大步 PASS 可能只是尚未受载。若要求近似相同位移分辨率，局部允许的物理步长或可随低速放大，但到首次接触的真实时间也大幅增加；根次数、总成本和全速阶段的可用步长不保证改善。20 ms 启动本身也不代表孔口通过或沉积。

## 必须先解决的运动一致性

`discrete_contact.py`、`contact_shell_finite_enclosure.py`、`visible_support_path_tight.py` 明确使用步内粒子直线、工具平移直线和最短测地旋转。已有可见图／壳面证书针对这条路径。另一方面 observer、候选事件采样、可见图及接触调用多处独立引用恒速 `pose`。只把其中一个 `pose` 换成解析 ramp 会使证书、接触、观察与输出不再描述同一条步内路径。

需要另立模型与初始化接口。可以显式采用按解析 ramp 节点构造的步内直线／测地近似，并让接触、证书、事件采样、observer 与能量使用同一有时间区间的运动对象；其节点加密改变的加载路径属于要验证的时间离散误差。若坚持步内精确解析 ramp，则必须另建包含平移／转动加速度的路径包络资格。两种方案均不能直接继承“全部旧资格已通过”的声明，也不能 monkeypatch 冻结模块。

## 最小可验证范围与否决条件

1. 先只验证新运动定义：积分／端点／导数连续性、任意步切分的累计位移、Tr 边界跨步、相同 interval-pose 在接触／采样／observer／证书中的一致性、刚体功与接触能量身份；维持原材料、物性、质量和轴约束。初始云可比对旧独立云，资格继承必须逐项证明。
2. 再进行少量有墙钟上限的独立初态 cost/root 探针，保持原 force、raw/full-prefix energy、热、接触及局部比较门槛。不能以接近零载荷的残差 PASS 证明输运可解，不能用 ramp 改变力或能量容限。
3. 若成本允许，再预注册从 t=0 连续推进到**真实首次接触及其后一段**的有限试验，完整保留初始能量前缀；粗细两条同父路径必须在受载区间比较。累计墙钟预算与允许的 dt 档数预先限定。到预算仍未覆盖有效受载区间则明确证据不足，不能跳到预估接触时刻或构造有利父状态。
4. ramp 初段过关后，仍须覆盖穿过率下限敏感区、达到额定速度和额定速度后的有限过程。若局部塑性分支误差再次要求微秒步，或成本仍不具备过程尺度可承担性，就停止把 ramp 当作数值解决方案，转向有边界的材料／积分方法审查。不能自动继续更长 ramp 或无界减半。

本评估只支持“启动历史值得做一次有界敏感性试验”，不支持“20 ms ramp 保证大步、可持续输运或完成沉积”。
