# 工具遮挡邻域失效后的最小修复边界（只读评估）

本轮只读源码、失败证据和一手文献，没有改冻结源，没有调用物理evaluate或试跑。
39.875ms未接受候选的7809条实际边中，PID219–251有132.760817nm严格工具实体
内部连续段；0.1nm内缩诊断仍为132.353203nm。它不是1nm阈值附近的舍入争议。
证据：post_passage_short_response/coarse/step_020/solid_edge_visibility.json。
原4ms窗仍FAIL，当前正式接受终时37.375ms；这份评估不修复或接受失败候选。

## 当前算子是否共用同一图

答案：当前QS材料路径的修正梯度、配对内力、粒子间导热和冻结搜索切线共用一次
真实endpoint NNPS得到的i/j/g；但几何可见性守卫在完整求根之后才检查，所以只能
拒绝结果，不能让残差在求根期间自动排除实体遮挡边。解析工具接触是另一条路径。

| 路径 | 实际入口与依赖 | 修改邻域时的要求 |
|---|---|---|
| 候选邻域 | mechanics.py:pairs/29 operators；3D LinkedListNNPS，仅欧氏支撑，无工具参数 | 在任何场梯度构造前得到统一无向可见边图 |
| 密度/修正/本构 | quasistatic_process.py:93→_geometry:41；同i/j/g随rho重算moment/B/H，再L=H/dt | 用过滤后图重建moment/B/H；保留正定/条件数1e6拒绝，不能复用旧B |
| 内力 | 同文件:138→mechanics.py:74 internal_force；使用B与同i/j/g | 必须同步；否则虚功共轭和角动量性质被破坏 |
| 导热 | 同文件:124→implicit_thermal.py:14/55 | 同可见图、原径向g和非负对称导热系数；不可把机械修正Bg送入导热 |
| 搜索切线 | quasistatic_process.py:166→gradient_map→assemble_frozen_force_tangent | 读取该residual的实际过滤图/B；它仍是冻结几何近似，不是完整Jacobian |
| 接触/壁热 | contact.evaluate与active面导热 | 继续独立算真实有限工具反力/热交换；删粒子边不等于施加壁面条件 |
| fresh/证据 | discrete_process.accepted_copy再次evaluate；Broyden每候选重算完整force | 重算必须恢复相同图政策；记录raw/active图及切换，不能只改输出i/j |

因此，单独在后处理中删除219–251边不能修复已算出的应力、ep、rho、温度、反力、
梯度、能量或根；也不能据剩余边图把旧候选改为PASS。

## 最小下一实现边界

建议独立版本增加纯函数图入口：输入raw NNPS无向i/j、当前实际x、工具pose、有限
实体参数与确定的容差政策，输出active i/j/g、blocked原边索引/区间、PID排序、
几何/图fingerprint。中心线遮挡判定可复用已验证解析几何；现有1nm仅是诊断阈值，
若将它用于离散模型，必须单独登记并做容差/分辨率敏感性，不能暗中内缩工具。

在独立Trial.evaluate里只构造一次这个图，密度修正、本构、内力、热与切线都取
同一快照。图不是trace/AS-RS的函数。保持原contact处理和守恒账；支撑退化就拒绝，
不许伪逆、扩大h、恢复穿墙边或造热以凑收敛。记录每次线搜索的图切换；跨图切换
应使Broyden搜索矩阵失效/刷新，预算内无法重新收敛就停，不能假称光滑精确切线。

这是离散空间模型变更，须新classification/source版本。若以后从37.375ms分叉，
先做父态同图与完整map等价读回、显式模型交接；不重置材料/温度/速度/ledger。
当前端点无遮挡证明不自动证明两端之间所有边始终无遮挡，图切换路径审计另需定义。

最低验证边界：

1. 无障碍3D仿射patch与刚体转动，过滤禁用时原map等价；过滤后有足够支撑的凹角
   patch检查一阶再现、质量不变、净内力/力矩和离散虚功，不能只数被删边。
2. 隔绝薄壁两侧冷热/受力块：跨壁内力与导热为零，同侧仿射响应/等温保持；壁反力、
   摩擦有符号功和壁热仍入原账。再做凹角、方孔口、有限肩面、刚体旋转协变。
3. 切线固定图定向差分、图切换两侧完整残差、接触粘滑/多面/释放热与可见图切换
   同时发生；步长对照与全部累计能量通过，不要求冻结切线等于完整导数。
4. 同一已存39.875ms失败候选只作新旧map差异诊断；真正通关必须从合格父新求根，
   新图全部四算子一致、fresh接受、空间/时间敏感性和无隐藏工具边路径证据。

若过滤后局部moment退化或凹角patch不收敛，最小滤边方案便不足，需另设计边界积分/
ghost或重构支撑。该升级不能在一次失败点临时拼补，也不能用已有接触罚力替代。

## 两条可借鉴的一手资料及其界限

Yao、Zhou、Berto（2020）在SPH核近似内加入diffraction criterion处理裂纹非凸体，
并用三类断裂算例检查；这支持“非凸支撑须进入空间近似”的方向。它处理裂纹，
并未验证本AFSD移动方孔、热塑性、摩擦或当前功热账；不能直接移植“绕射”让
材料/热隔着工具相连。[作者论文与DOI](https://doi.org/10.1016/j.tafmec.2020.102584)

Jacquemin、Bordas（2021）给出2D/3D可见性支撑选择算法，并声明附代码和数据；
论文用GFD线弹性测试凹域，还展示可见性规则并非对所有几何都自动降低误差。
可借鉴几何/凹角基准，不能称已得到可直接替换PySPH的AFSD库；本轮未核实附件
代码的开源许可证，也不采用文中角度容差去放行132nm穿墙边。
[作者开放论文](https://onlinelibrary.wiley.com/doi/full/10.1002/nme.6703)

本次没有核实到可直接接入当前热塑性守恒链、同时解决障碍物支撑和图切换的现成
官方AFSD组件。最小可交付下一项是“统一可见边图+四算子同图+上述基准”的独立
组件资格，之后才登记有界过程重试；几何滤边代码本身不等于问题已解决。
