## 选择问题与接口

旧Q7的0.2s是冻结参考构形的小应变制造组件；当前真实342点轨迹只有700ns。
先查实际更新次序，不能把Q7的制造J2、固定面/统一平移边界移入AFSD。
新残差允许后续全局迭代复用原真实3D内力、材料、接触、温度与PySPH数组；不调用积分器推进。
未知量是自由x1/v1、约束反力及接触乘子；本轮只验证给定候选的下列必要方程：

```text
Rx = x1-x0 - dt*(v0+v1)/2                   [m]
Rm = m*(v1-v0)/dt - (Fint+Fcontact+Fext+R) [N]
Rc = (1-P)*(v1-vprescribed)                 [m/s]
Rq = -P*(Fint+Fcontact+Fext)                [N]
```

P=diag(free_axes)，R为显式输入的约束反力。只输出Rq供准静态可忽略惯性诊断，不把Rm自动替成Rq。
恒定轴向执行器的端速度约束适用；切换/变速程序必须另分事件，不由本接口吞掉。
Fcontact可以是实际接受区间总接触冲量/dt，用于本轮轨迹账；未来求根须从同一候选求接触反力，
不能冻结上一解接触力然后宣称全耦合收敛。材料trial每次必须从同一last accepted history开始，不累积Newton试探。
实际contact子区间功不能用总冲量与全步端点平均速度替代，任何端点功surrogate都不得用来生成热。
本接口不接受label/tracer/ASRS，输入质量必须正/有限且不更改；不剪裁残差或隐去自由轴反力。

## 独立参考与容限（测前）

- 一点三维对角弹簧，m=1kg，K=diag(4,9,16)N/m，dt=.2s，x0=(1,0,-1)m，v0=(0,2,1)m/s，
  恒F=(.5,-1,3)N；独立代数隐式中点v1=(-35/52,162/109,4)m/s，x1=x0+.1*(v0+v1)。
  Fint=-K*(x0+x1)/2；无接触/约束。动量/运动学零，动能+弹簧能增量=F·(x1-x0)。
- m=1kg单自由轴，x0=1m/v0=0，K=4N/m，无外力；至t=1s的连续参考cos(2),-2sin(2)。
  h=.25/.125/.0625s；中点离散相位theta=2*atan(h)，每步能量守恒但有限相位误差，细化应约二阶。
  这只验证时间残差，不验证SPH空间/接触或真实AFSD可用大步。
- 约束反力、自由轴反力暴露、静平衡/有惯性反例、三分量/重排、输入不变及坏输入拒绝。
- 制造残差/功参考atol1e-12 SI；相位与离散字面公式atol1e-12，连续误差须随两次折半严格减小，
  比值<.27（该线性光滑问题二阶预期约.25，非工程AFSD精度门槛）。
- 摩擦反向的独立限制例：m1/u0=1/Fother=-2/muFn1/dt1时，uf=-2/3、真实Q=7/18、
  Jt=1/3，端点平均u=1/6却给Qsur=-1/18；真实位移=-1/18而端点平均漂移=1/6。
  因此大步动量残差闭合不能证明事件/热/运动学正确；隐式候选必须保留事件分段。
  只读评估另报区间总接触冲量×端点平均速度与真实子区间接触功的差，绝不作补热。

## 真实数据一次只读评估

验证COUPLED_AFSD_FREEZE及short_07us source/config/artifact哈希，逐完整67步取真实trace冲量。
Jint=dt*Fint；逐所有接触feature/子区间累加Jn/Jt/R，绝不只取某一面。
报告每步P*m*delta_v/dt与P*(Fint+Fc)的关系、各分量力范数、
rq_ratio=norm(Rq)/sum(norm(P*各物理力分量))；分母零时输出null和状态，不默认0。
既不以全局合力相互抵消假装局部平衡，也不按标签剔除某些自由粒子。
报告初始预压/实际K、局部塑性态、最终态、初始工具宏观速度尺度和全轨迹残差，不拟合终时。
运动学误差界1e-15m+128eps*位置尺度，动量界1e-12N+1e-10*力尺度（同时保留原始数值）。
这些只验证接口/读回代数；本轮不新设准静态生产验收阈值，不因为某比值小就认证无惯性。
整个窗口不能证明稳定过程；只要Rm闭合而Rq明显非零，就不能直接把此瞬态当作已平衡初态。
