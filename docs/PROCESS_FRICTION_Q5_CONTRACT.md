# Q5 短切向摩擦：运行前合同（2026-10-01）

本单元只做单壁、弹性、Y定向Coulomb摩擦，Z无摩擦；真实三维材料/力/自由分量，
但不是各向同性双切向摩擦锥，也不替代AFSD生产contact。旧代码/配置/tests/FAIL不改。
源自Q3/Q2的实际trial/tangent/material.update和corrected伴随力；不替换成线性弹簧。
新companion scripts/probe_process_friction.py；制造弹簧仅独立测试算法，不替代块体。

## 物理问题和调用

同27点[0,.01]^3m、rho2700、E70GPa、nu0、制造elastic yield1e12Pa、规定293.15K。
本基准明确改变支承：**仅X=0面三分量夹持**，移除Q3的Y/Z零面roller，避免
壁切向与永久支承重合。材料仍可变形，54自由DOF；9个X+边界候选法向接触。
全端夹持和自由侧面存在翘曲，不能以GA/L当整个块的精确连续体刚度。
接触法向-X；λ=Fint_x正压，gap=dX-uX；本阶段预压保持，不支持脱离，若λ越界BLOCK。

0-.05s壁X压入0→-40um，Y=0；之后X保持；.05-.1s壁Y0→+20um，
.1-.15s回到-20um，.15-.2s回到0。四个拐点必须实际接受，时间只是准静态程序。
μ=.1是制造假设，非论文参数。温度/摩擦热传导不求解，耗散仅独立功账。

每增量先检验粘着可行性；mode=0粘着，±1代表材料相对壁的滑移方向。
粘着：uY=uY_old+ΔwallY，|τ|<=μλ；滑移：τ=-μ*mode*λ。
共享全局平衡，自由滑移行R_y=Fint_y-μ*mode*Fint_x；其Newton行
K_y-μ*mode*K_x，保留法向/切向/其他自由DOF耦合，不以P/m独立限幅。
每次trial都从同accepted材料状态计算，迭代不积累应力/ep；提交前重算全部。

短单调程序分支内检测首次粘滑边界，分段接受后继续；壁反向先尝试粘着卸载，
不能直接按壁速翻转力。分支探测为本制造路径的局部方法，不证明任意多事件检测。
同一请求区间最多12事件、16模式迭代、40二分、时间括宽1e-12s。
保留Q3力容限9e-5N、位移1e-11m、功1e-6J；正常反向滑移本身不是失败。
逐接触raw Q=-tau_mid*Δ(uY-wallY)先检查，再求和，不裁负值/取绝对值。
负值<-1e-10J拒绝；更小负尾值照实存档，不归零。该量纲容限防迭代残差放大，
不宣称1e-10J以下必为浮点误差。核心条件还包括模式、接触平衡和反向路径正确。
必须分别记录Wwall、Wmaterial、Wsupport、Wstress、Q，检查
Wwall-Wmaterial=sumQ及Wmaterial+Wsupport=Wstress。储能差另报，不补热。
每区间另存Jt=tau_mid*Δt、relative_kinematic_rate=Δslip/Δt；
Q=-Jt*relative_rate是准静态区间积分，不冒充显式动力学kick中点速度。
